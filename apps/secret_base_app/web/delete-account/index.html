앱에서 삭제

더보기 → 내 공간 → 회원 탈퇴에서 안내를 읽고 확인하세요. 이메일 가입자는 현재 비밀번호가 필요합니다. Google 가입자는 비밀번호를 입력하지 않습니다. 연결 해제는 계정 삭제와 다릅니다.

앱 없이 이메일로 요청

가입한 이메일 주소를 입력하면 담당자에게 보낼 삭제 요청 메일 초안을 엽니다. 메일 앱에서 내용을 확인하고 직접 전송해야 요청이 접수됩니다. 이 페이지는 이메일 주소를 서버에 전송하거나 저장하지 않으며, 비밀번호·인증 코드를 요구하지 않습니다. 담당자가 본인 확인 후 처리하는 흐름입니다.

현재 검증된 운영자 및 삭제 요청 수신 이메일이 미확인이므로 이메일 요청 버튼을 사용할 수 없습니다. 담당자와 실제 수신 가능한 주소가 확인된 후 활성화해야 합니다. 그 전에는 앱의 회원 탈퇴를 이용해 주세요.

삭제 요청 수신 이메일 미확인 — 이메일 접수 준비 중입니다.

삭제 및 보관 범위

현재 앱 탈퇴는 로그인용 식별 정보를 대체하고 활성 커플을 비활성화하며, 본인이 작성한 MomentLoop 기록을 삭제하고 미디어 파일 삭제를 시도합니다. 본인의 장소 중 다른 기록이 참조하는 장소는 작성자 연결을 제거해 남기며 나머지는 삭제합니다. 파트너 작성 기록은 자동 삭제하지 않습니다.

탈퇴 표식, 출생 정보, 심리검사·상담·알림 등 다른 기능의 잔여 데이터와 백업의 완전 파기 범위·기한은 아직 확정되지 않았습니다. 운영 문서는 백업 30세대 보관을 설명하지만 실제 실행 주기와 만료 여부는 미확인입니다. 모든 정보가 탈퇴 후 30일 이내 삭제된다고 보장하지 않습니다. 개인정보 처리방침 초안의 보관 및 파기 제한을 확인하세요.

운영자 법적 명칭·개인정보 담당자·검증된 문의 및 삭제 요청 이메일: 미확인. 기존 앱의 팀 소개와 고객센터 표기만으로 담당자와 메일 수신 가능 여부를 검증하지 않았습니다. 공개 확정 전에 오너 확인이 필요합니다.
