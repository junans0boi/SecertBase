개인정보 처리방침

Secret Base (시크릿 베이스) · 문서 초안 업데이트: 2026-10-12

법률 검토 미완료. 이 문서는 현재 구현을 설명하는 초안입니다. 부모 이슈 #139에서 법률 검토는 범위 밖이며, 법률 검토 완료나 스토어 정책 충족을 의미하지 않습니다.

1. 수집 항목과 목적

  • 가입 및 로그인: 이메일, 비밀번호 해시(원문 비밀번호가 아닌 bcrypt 해시), 이름, 닉네임, 생년월일. Google 로그인 시 계정 식별자, 이메일, 이름 및 프로필 사진 정보를 받아 인증과 프로필 제공에 사용합니다.
  • 프로필 및 커플 연결: 프로필 이모지, 초대·연결 코드, 파트너 관계, 기념일, 접속 상태를 관계 연결과 앱 기능 제공에 사용합니다.
  • 사용자가 올린 기록: 사진, 짧은 영상, 메모, 감정 태그, 기록 일시, 장소 연결, 댓글·반응 및 앨범 자료를 기록 저장과 커플 공유에 사용합니다.
  • 장소 및 위치: 지도에 입력·저장한 장소 이름, 주소, 좌표, 방문 날짜와 장소 후기를 보관합니다. 위치 권한을 허용할 때 현재 위치를 지도·주변 장소 검색에 사용하며, 마음관리 안전 안내에서는 국가·행정지역을 일시 사용합니다. 출생지를 현재 위치로 추정하지 않습니다.
  • 관계 이해: 출생 정보(양력·음력, 윤달 여부, 출생 시각·시간대·출생지), 심리검사 응답·결과·이력, 궁합 분석, 운세·타로 선택과 결과를 해당 기능 제공에 사용합니다.
  • 마음관리 및 상담: 감정 체크인, 선택 응답, 자유 입력, 상담 대화, 요약 및 사용자가 승인한 공유 힌트를 저장합니다. 의료 진단이나 치료를 제공하는 기능이 아닙니다.
  • 알림 및 서비스 이용: 알림을 등록한 기기의 푸시 토큰, 플랫폼·등록 상태·알림 설정, 게임 진행·결과, 기능 이용 이벤트와 접속 상태를 기능 제공과 알림 전송에 사용합니다.

위 항목은 기능을 선택하거나 데이터를 입력할 때 수집되는 항목을 포함합니다. 실제 운영 로그의 항목·접근 권한·보관 기간은 아직 확인되지 않았습니다.

2. 공유 범위 및 외부 서비스

커플 공유 기록과 공유 결과는 활성 커플의 두 사용자에게 제공됩니다. 개인 심리검사 원문과 프라이빗 상담 원문은 파트너 및 일반 사용자 API에 공개되지 않습니다. 프라이빗 원문은 현재 저장 시 암호화 및 운영자 접근 감사가 적용되지 않아, DB 접근 권한이 있는 운영자가 확인할 수 있습니다.

Google 로그인, 지도 타일·장소 검색, 푸시 전송 등 외부 서비스에 해당 기능의 요청 정보가 전달될 수 있습니다. 선택적 LLM 설명·요약이 운영 설정에서 활성화되고 사용자가 요청한 경우 해당 기능의 입력 맥락이 설정된 외부 제공자에게 전달될 수 있습니다. 실제 제공자, 전송 항목, 처리 지역, 위탁·국외 이전 여부와 보관 정책은 오너 확인 및 법률 검토가 필요합니다. 외부 전송이 전혀 없다고 보장하지 않습니다.

3. 보관 기간과 현재 삭제 동작

계정을 사용하는 동안 기능별 기록을 보관합니다. 커플 연결 해제는 계정 삭제가 아니며 개인검사 기록과 과거 커플 범위 기록을 자동 파기하지 않습니다. 재결합·과거 기록 보기에 필요한 기록은 남을 수 있습니다.

앱의 회원 탈퇴는 로그인용 이메일·이름·비밀번호 등 식별 필드를 대체한 탈퇴 표식(tombstone)을 남기고 활성 커플을 비활성화합니다. 본인이 작성한 MomentLoop DB 기록을 삭제하고 관련 미디어 파일 삭제를 시도합니다. 장소는 다른 기록과 연결되어 있으면 작성자 연결을 제거해 보관하고, 연결되지 않은 장소는 삭제합니다. 파트너가 작성한 기록은 자동 삭제하지 않습니다.

현재 삭제 API는 생년월일·추가 출생 정보, 검사·상담, 알림 및 기타 기능 테이블 전부를 파기하는 처리가 확인되지 않았습니다. 남은 정보의 파기 범위와 기한, 파일 삭제 실패 시 재처리, 탈퇴 표식 보관 기간도 미확인입니다. 계정 삭제가 모든 정보의 완전 파기를 뜻하지 않습니다.

운영 백업 문서는 DB와 업로드 파일의 최근 30세대 보관을 설명합니다. 이는 매일 실행할 때 약 30일이며, 실제 실행 주기·백업 만료와 복원 시 삭제 정보의 재삭제 절차는 미확인입니다. 계정 삭제 후 30일 이내 전체 파기는 목표 초안일 뿐 현재 보장할 수 있는 처리 기한이 아닙니다. 법정 보존 항목·근거·기간도 법률 검토 후 확정해야 합니다.

4. 권리 행사 및 삭제 요청

앱의 더보기 → 내 공간 → 회원 탈퇴에서 삭제를 진행할 수 있습니다. 이메일 가입자는 현재 비밀번호를 확인하며 Google 가입자는 비밀번호 입력 없이 진행합니다. 앱을 사용할 수 없는 경우 계정 삭제 요청 페이지를 확인하세요. 이메일 접수는 검증된 담당자 주소가 확정될 때 활성화됩니다.

5. 보호 조치와 문의

비밀번호 해시, 인증 및 사용자·커플 범위 접근 제한, 운영 HTTPS 전송을 적용합니다. 프라이빗 상담을 포함한 모든 저장 데이터가 암호화되어 있다고 보장하지 않습니다. 열람·정정·추가 파기 등 권리 행사 담당자와 연락처는 아래와 같이 미확인입니다.

운영자 법적 명칭·개인정보 담당자·검증된 문의 및 삭제 요청 이메일: 미확인. 기존 앱의 팀 소개와 고객센터 표기만으로 담당자와 메일 수신 가능 여부를 검증하지 않았습니다. 공개 확정 전에 오너 확인이 필요합니다.
