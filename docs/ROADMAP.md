# Secret Base 로드맵

최종 정리: 2026-09-10

## 완료된 기반

- 2인 인증·파트너 연결·활성 Couple 흐름
- 커플 홈, D-day, MomentLoop, 비밀 지도, 놀이 탭
- 더보기·내 공간·프로필·출생 정보·기념일·계정 관리 흐름
- 윷놀이, UNO, 폭탄 돌리기와 가벼운 실시간 게임
- 관계 이해, 개인 검사와 커플 범위 결과 분리
- MariaDB·Redis 기반 운영 서버와 HTTPS 배포
- 운영 도메인 `https://secretbase.cloud`

## 유지 원칙

- 제품 용어와 사용자 데이터 경계는 `CONTEXT.md`를 기준으로 한다.
- 현재 실행 구조와 운영 값은 `docs/PROJECT_OVERVIEW.md`와 `docs/deployment/`를 기준으로 한다.
- 날짜가 붙은 handoff는 당시 세션의 기록이며 현재 상태를 대신하지 않는다.
- 구현되지 않은 기능을 완료 항목으로 다시 올리지 않는다.
