# Handoff — 2026-09-10 운세·마음관리·검사 UX 확장 설계

## 이번 세션에서 확정한 방향

- 홈의 `오늘의 운세`와 `관계 이해`는 이미 독립 카드이며, 운세를 관계 이해 허브의 개인 탭에서 제거한다.
- 운세는 사주·타로로 오늘 하루의 흐름을 자세히 살펴보는 자기성찰 콘텐츠로 확장한다.
- 개인검사 4개와 커플검사 3개 모두 진행률, 완료일, 과거 기록, `새 검사하기`, 최근 2회 차원별 변화 비교를 같은 UX로 제공한다.
- 상담사 검색·예약·결제는 제외한다.
- 마음관리는 선택지 기반 개인 흐름으로 시작한다: 감정 → 상황 → 필요한 것 → 작은 행동 → 완료.
- 자해·자살·폭력 위협·심각한 공황 등 위험 신호가 선택되면 일반 추천보다 상황별 안전 안내를 먼저 제공한다.
- LLM은 선택적 자연어 보조이며 점수·위험도·권한·치료 판단을 결정하지 않는다.

## 2026-09-10 구현 진행 메모

- 개인·관계 사주, 메이저 22장 타로, 10단계 개인 마음관리 guided chat, 서버 안전 리소스 API,
  개인·커플 검사 변화 비교 REST/Flutter slice를 작업 트리에 추가했다.
- 마음관리와 안전 리소스는 인증 owner 범위, 고정 콘텐츠 버전, 위험 후보 안전 확인을 유지한다.
- 안전 리소스는 `safety-kr-v1` JSON에서 국가·행정지역만 일시 사용하며 좌표 query/body를 거부한다.
- 테스트 DB/Redis 환경이 없는 상태에서 Node 전체 테스트는 통합 fixture를 skip하고 unit은 통과한다.
  Flutter 관련 widget/API 테스트와 `flutter analyze --no-pub`를 실행한다.
- 아직 운영 배포·커밋·푸시는 하지 않았다. Flutter 위치 권한/지역 리소스 표시와 권한 거부
  fallback을 구현했고 관련 API/widget 접근성 테스트와 `flutter analyze`를 통과했다. 남은
  작업은 테스트 DB/Redis URL을 제공한 인증 REST smoke 및 실제 기기 beta 점검이다.
