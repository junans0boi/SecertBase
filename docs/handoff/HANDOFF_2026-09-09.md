# Handoff — 2026-09-09 UI·계정 정리와 운영 배포

어제는 앱의 메인 내비게이션과 계정 관리 흐름을 하나의 제품 언어로 정리하고, 수정 결과를 운영 서버까지 배포했다. 이 문서는 당시의 사용자-facing 결정과 배포 검증을 기록한다. 현재 도메인·제품 용어는 루트 `CONTEXT.md`를, 현재 실행 구조는 `docs/PROJECT_OVERVIEW.md`를 기준으로 본다.

## 메인 내비게이션

하단 탭은 다음 다섯 개로 고정했다.

```text
홈 | MomentLoop | 지도 | 놀이 | 더보기
```

- 홈은 커플 이름과 D-day를 먼저 보여주고, `오늘 기록`을 MomentLoop로 들어가는 대표 진입점으로 둔다.
- 홈의 지도·놀이 바로가기는 각 탭으로 이동한다.
- MomentLoop는 하단 탭으로 독립시켜 홈에 같은 목적의 진입 버튼이 반복되지 않게 했다.
- 더보기 탭의 화면 제목은 `전체`다. 여기에서 MomentLoop·지도·놀이·관계 이해·비밀기지와 계정 관리를 찾는다.
- 더보기에서 상세 화면으로 이동해도 `HomeShell`의 하단 내비게이션이 유지된다. 상세 화면을 닫지 않고도 다른 탭으로 이동할 수 있다.

## 내 공간

더보기의 프로필 요약을 누르면 `내 공간`으로 이동한다. 내 공간은 다음 순서와 역할을 갖는다.

1. 프로필 요약과 수정
   - 이름
   - 닉네임
   - 생년월일
   - 운세용 출생 정보로 이어지는 출생 시각·달력 유형·시간대·출생지 수정
   - 로그인 방식과 Google 연동 상태
   - 이메일 계정의 비밀번호 변경
2. 계정 및 연결
   - 연결된 애인 확인과 연결 해제
   - 커플 시작일을 기념일로 추가하거나 수정
3. 프로필 이모지
4. 연결 상태와 현재 접속자
5. 로그아웃
6. 회원 탈퇴
7. 개발자 정보

프로필 수정과 기념일 수정은 회원가입·로그인 화면과 같은 `AuthTheme` 계열의 바텀시트 입력 경험을 사용한다. 기념일 저장은 인증된 사용자의 커플 시작일을 갱신하고 저장 후 최신 커플 정보를 다시 읽는다.

## 백엔드 계약

- 프로필 수정은 인증된 사용자 자신의 프로필만 갱신한다.
- 커플 정보 조회와 시작일 수정은 인증 토큰의 활성 Couple을 기준으로 한다.
- 연결 해제와 회원 탈퇴는 각각 관계 상태 변경과 계정 종료로 구분한다.
- 출생 프로필은 개인 범위이며, 관계 이해 화면에서 상세 출생 정보를 수정한다.

## 브랜딩과 시각 언어

- 새 Secret Base 심볼·워드마크를 Android 아이콘, 웹 아이콘, 스플래시와 앱 화면에 연결했다.
- 메인 앱은 밝은 종이색 배경, 잉크색 텍스트, 장미·세이지·스카이·라일락·허니 포인트를 사용하는 공통 디자인 토큰을 사용한다.
- 인증 화면과 내 공간 입력 화면은 둥근 카드와 넉넉한 여백을 공유한다. 핑크 한 색에 의존하지 않고 기능별 포인트 색을 나눠 사용한다.
