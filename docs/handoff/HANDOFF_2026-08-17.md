## 미수정 / 알려진 이슈

### 🟡 윷: `piece_safe_zone_pct` 실제 기능 구현 없음

레이블만 수정했고, 실제 서버 코드에 "모서리 착지 확률 보너스" 로직은 없음.
현재는 `piece_catch_resist_pct`와 완전히 동일한 잡히기 방지 로직으로 동작.
추후 실제 기능 설계 및 구현 필요.

### 🟡 윷: throw 핸들러 stats DB 재조회

`game:yut:throw` 핸들러가 매번 `getEquippedStats()`로 DB 조회.
`game:yut:move`는 `gameState.playerStats` 캐시 사용.
→ 게임 도중 아이템 교체가 불가하면 throw도 캐시 사용으로 통일 권장 (성능 + 일관성).

### 🟢 윷: 걸→윷→모 연쇄 확률 업그레이드

`yutControlPct`로 걸이 윷이 되고 다시 `yutMoRatePct`로 모가 될 수 있음 (직통 경로).
의도 여부 불명. 주석 추가 또는 방어 로직 필요.
