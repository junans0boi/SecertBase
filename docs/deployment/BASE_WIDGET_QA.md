# 기지 위젯 (Android 홈 화면 위젯) 수동 확인

플랜: `docs/plans/couple-parity-2026-11/issues/04-base-widget.md`. 에뮬레이터·실기기가 없는 환경에서
구현했으므로(빌드·단위·위젯 테스트까지만 통과) 아래 절차로 한 번 확인해 주세요.

## 구조
- Dart: `lib/features/base_widget/` — `BaseWidgetData`(마스킹·직렬화), `BaseWidgetService`(갱신·비움·탭 라우팅), `HomeWidgetStore`(home_widget).
- Kotlin: `DdayWidgetProvider`(D-day + 다음 기념일), `TodayWidgetProvider`(마주 열기 상태 / 오늘의 루프 공개 / 안 읽은 쪽지 수).
- 위젯에 쓰는 키는 `active, dday, ann_label, ann_days, qa_state, loop_open, unread, as_of` 뿐이다.
  쪽지 본문·질문·답변·사진·장소·파트너 이름은 위젯 저장소에 쓰지 않는다(`base_widget_test.dart`가 검증).
- 갱신 시점: 홈 로드, 마주 열기 카드 로드(제출 후 홈 복귀 시 재로드), 쪽지 읽지 않은 수 갱신/수신(소켓), 앱이 켜진 상태의 푸시 수신.
- 비움: 로그아웃, 연결 해제 성공 시. 이후 위젯은 "앱을 열어 연결을 확인해 주세요"로 보인다.
- 위젯 탭: `secretbase://widget/{home|two_answers|notes}` → 기존 `pendingPushTarget` 경로(홈 / 마주 열기 / 쪽지).

## 절차 (에뮬레이터 API 31+ 또는 실기기)
1. `flutter run` 또는 `flutter build apk --debug` 후 설치, 커플 연결된 계정으로 로그인해 홈을 한 번 연다.
2. 홈 화면 길게 누르기 → 위젯 → "비밀기지"에서 `기지 위젯 · D-day`, `기지 위젯 · 오늘 상태`를 배치한다.
3. D-day: `D+N`과 "다음 기념일 · N일 남음"이 앱 홈과 같은지. 탭하면 앱 홈이 열린다.
4. 오늘 상태: 마주 열기(내 차례/기다리는 중/열렸어요), 오늘의 루프(공개됨/아직 닫혀 있어요), 쪽지(없음/N개 안 읽음).
   - 상대 계정으로 쪽지를 보내면 앱이 켜진 동안 숫자가 오른다. 쪽지를 읽고 홈으로 오면 줄어든다.
   - 마주 열기 행 탭 → 마주 열기 화면, 쪽지 행 탭 → 쪽지 화면(앱이 종료된 상태에서도).
5. 잠금 화면/위젯 어디에도 쪽지 본문·질문·답변이 나오지 않는지 눈으로 확인한다.
6. 설정에서 로그아웃(또는 연결 해제) → 위젯이 즉시 빈 안내 상태가 되고 숫자·기념일이 남지 않는지.
7. 다음 날 앱을 열지 않고 위젯을 보면 D-day가 하루 늘어 있는지(`as_of` 기준 Kotlin 계산).

## 알려진 한계
- 앱이 완전히 종료된 상태의 푸시로는 위젯을 갱신하지 않는다(Dart 백그라운드 핸들러 없음). 다음에 앱을 열 때 갱신된다.
- 위젯 색은 정적 리소스라 앱의 화면 테마 선택을 따르지 않고 기본(blossom) 토큰 값을 쓴다.
- iOS는 범위 밖(프로젝트 없음).
