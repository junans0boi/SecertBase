# 검사 기록은 문항별 선택 답변을 함께 보존한다

완료된 개인검사 기록은 결과 점수만 남기지 않고 해당 시도의 문항별 선택 답변과 문항 버전 연결을 유지한다. 기록 목록에서 사용자가 특정 결과를 선택하면 당시 질문·차원·리커트 선택값을 읽기 전용으로 확인할 수 있게 하며, 재검사는 기존 기록을 수정하지 않고 새 시도를 만든다. 이렇게 해야 사용자가 결과가 어떤 응답에서 나왔는지 이해하고 시간에 따른 변화를 비교할 수 있다. 개인 원문 응답은 계속 사용자 범위로 제한하며 커플 공유 결과에는 포함하지 않는다.
