# 관계이해 공유 데이터는 Couple lifecycle 경계를 따른다

개인검사와 출생 프로필은 사용자 범위 데이터다. 연결 해제해도 본인이 자신의 개인검사 history를 계속 조회할 수 있고, 새 파트너에게 이전 개인 원문이나 결과가 자동으로 노출되지 않는다.

커플검사 결과, 궁합 분석, 궁합의 자연어 설명은 `couple_id` 범위 데이터다. 활성 Couple이 아닐 때 관련 API는 `active_couple_required`로 차단한다. 같은 두 사용자의 재결합은 기존 비활성 Couple을 다시 활성화하므로 기존 공유 범위를 복원할 수 있다. 다른 파트너와 새로 연결하면 새 Couple ID를 사용하므로 이전 Couple의 공유 결과를 읽을 수 없다.

## Consequences

- Separation은 공유 데이터를 삭제하지 않고 접근 경계를 닫는다.
- Reunion은 새 Couple과 새 분석 공간을 임의로 만들지 않는다.
- 새 파트너 연결은 이전 Couple의 커플검사·궁합·설명 생성 레코드와 분리된다.
- 개인검사 history와 커플 결과의 수명이 다르므로 API와 Flutter 화면에서 상태를 구분해 설명해야 한다.
- Couple 데이터의 영구 보존·정리 정책은 기존 데이터 보존 정책과 별도의 운영 작업으로 남는다.
