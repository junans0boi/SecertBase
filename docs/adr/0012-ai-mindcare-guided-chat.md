# 마음관리는 AI 가이드 채팅으로 진행하되 고정 단계가 흐름을 통제한다

마음관리 v1은 상담사처럼 느껴지는 말풍선 채팅을 제공하지만 실제 사람 상담사나
상담사 marketplace는 포함하지 않는다. AI 마음관리 가이드는 따뜻한 존댓말을
사용하고, 빠른 선택지와 선택적 자유 입력을 받는다. 사용자는 한 세션에서
10~12회 정도 응답하며 감정·상황·필요·작은 행동·완료 확인 흐름을 진행한다.

다음 질문, 선택지, 작은 행동, 안전 안내의 의미는 버전 있는 고정 콘텐츠가
결정한다. 선택적 LLM은 이미 결정된 내용을 자연스러운 문장으로 다듬거나 사용자가
요청한 자유 입력을 요약할 수 있지만, 위험도·진단·치료·행동·공유 권한을 결정하지
않는다. provider 장애나 비활성화 시 고정 문구를 사용한다.

세션과 메시지는 사용자 범위로 저장하고 최근 미완료 세션 하나를 재개한다. 파트너와
Couple API에는 자동 노출하지 않으며, 공유 승인 기능은 이 결정에 포함하지 않는다.
서버의 고정 한국어 표현 사전이 위험 가능성을 표시하면 자동 판정하지 않고 현재
안전 여부를 묻는 안전 안내 상태로 전환한다.

## 구현 상태 (2026-09-10)

`relationship_mindcare_sessions`와 `relationship_mindcare_messages`에 상태·응답 수·
콘텐츠 버전·원문을 저장하고, 인증된 `POST/GET /api/relationship/mindcare/sessions`,
메시지, 안전 확인 API를 제공한다. 고정 콘텐츠는 10단계로 감정·상황·필요·작은 행동·
완료를 진행하며, Flutter `MindcareScreen`은 말풍선과 빠른 선택지, 선택적 자유 입력을
보여준다. 위험 후보는 안전 확인으로 멈추고, 현재 안전하지 않다는 응답에는 고정 즉시
도움 문구를 표시한다.

## Consequences

- 기존 private counseling 저장·권한 원칙을 재사용할 수 있지만 mind-care 상태와 콘텐츠 버전을 별도로 보존한다.
- 자유 대화의 상담사 대체 오해를 줄이면서도 선택지만 누르는 흐름보다 자연스러운 UX를 제공한다.
- 10~12회 길이와 고정 단계는 무제한 대화·스트리밍·백그라운드 생성을 제외한다.
- 마음관리 콘텐츠는 감정 8개, 상황 6개, 필요 6개, 텍스트·체크 기반 작은 행동 24개로 시작한다.
