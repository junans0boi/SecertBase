# 검사 변화 비교는 같은 버전의 최근 두 완료 기록을 중립적으로 보여준다

검사 기록의 변화 비교는 개인검사와 커플검사에 같은 정보 구조를 사용하되 기록의
범위를 지킨다. 개인검사는 사용자의 같은 검사 버전 결과 중 최근 두 건을 비교한다.
커플검사는 같은 활성 Couple과 같은 검사 버전에서 확정된 공유 결과 중 최근 두 건을
비교한다. 커플 구성원의 원문 응답과 개인 점수는 비교 응답이나 화면에 포함하지 않는다.

커플 공유 결과는 두 구성원의 완료 시도 조합으로 식별한다. 한 구성원이라도 새 시도를
완료하고 두 사람이 같은 버전을 충족하면 새 조합을 하나의 읽기 전용 공유 기록으로
확정한다. 같은 조합으로 중복 기록을 만들지 않으며, 이전 공유 결과는 보존한다.

비교는 인증된 REST API가 계산한다. 개인 차원과 커플 `pairScore`는 주 변화 지표로
사용하고, 커플 `alignmentScore`는 별도 보조 지표로 제공한다. 서버는 같은 버전의
최근 두 기록만 선택하고 이전·현재 값과 변화량을 구조화해 반환한다. 최근 기록이 한
건뿐이면 오류 대신 비교 불가 상태를 반환한다. 서로 다른 버전의 기록을 섞어 비교하지
않는다.

Flutter는 비교 결과를 모바일 카드로 표현한다. 기존 Secret Base의 둥근 카드와 부드러운
색상 토큰을 사용하고, 막대 또는 꺾은선 같은 귀여운 시각화는 수치와 텍스트를 보조한다.
색상이나 장식만으로 의미를 전달하지 않으며 `이전 42점 → 현재 58점 · 16점 높아짐`,
`변화 없음`, `16점 낮아짐`처럼 이전·현재·변화량을 항상 읽을 수 있게 한다. 성격 라벨,
개선·악화, 관계의 우열을 자동으로 붙이지 않는다.

결과가 한 건뿐인 경우 화면은 `이 검사를 한 번 더 완료하면 최근 변화를 볼 수 있어요.`를
보여주고 `다시 검사하기`로 연결한다. 구버전 기록은 계속 열람할 수 있지만 최신 버전의
비교 대상에 대신 사용하지 않는다.

## 구현 상태 (2026-09-10)

개인 `GET /api/relationship/assessment-results/:code/comparison`와 커플
`GET /api/relationship/couple-assessment-results/:code/comparison`가 인증된 같은
버전의 최근 두 기록을 계산한다. Flutter 이력 화면은 `최근 변화` 둥근 카드에서
이전·현재·변화량을 텍스트로 함께 보여주며, 기록이 한 건이면 재검사 안내를 표시한다.

## Consequences

- 비교 계산과 버전 경계가 서버 계약에 고정되어 Flutter와 API가 서로 다른 결과를 만들지 않는다.
- 개인 기록과 커플 공유 기록의 수명·권한 차이를 유지한다.
- 새 공유 결과를 추가해도 과거 결과를 수정하지 않는다.
- 비교 화면은 점수 변화의 사실만 보여주며 임상적·관계적 판단을 제공하지 않는다.
- 차트 모양은 구현 단계에서 접근성 텍스트 계약을 깨지 않는 범위에서 조정할 수 있다.
