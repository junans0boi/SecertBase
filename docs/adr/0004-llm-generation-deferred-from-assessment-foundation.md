# 심리검사와 관계 콘텐츠의 핵심 판정은 결정론적으로 계산하고 LLM은 보조한다

현재 작업에서 출생 정보, 버전이 있는 고정 문항, 점수 계산, 비임상적 개인 결과와 커플 궁합 판정은 결정론적으로 구현한다. LLM은 결과의 자연어 설명과 운세·상담 응답을 보조하는 선택적 계층으로 사용하며, 특정 공급자에 고정하지 않고 무료 API를 연결할 수 있는 provider adapter로 격리한다. 운세의 콘텐츠 버전, 상담의 세션 범위·공유 힌트, 검사 점수와 궁합 판정은 LLM 밖에서 결정한다. 이렇게 하면 LLM 공급자와 생성 품질에 의존하지 않고 데이터 경계·권한·검사 버전을 검증하면서도 자연어 경험을 향상할 수 있다.

## Consequences

- 점수와 궁합 판정은 LLM 없이도 완전한 결과를 반환해야 한다.
- LLM 설명 생성이 실패하거나 비활성화되어도 고정 템플릿 결과를 fallback으로 제공한다.
- LLM 연동을 위해 검사 결과와 궁합 분석에 버전과 설명 생성 상태를 보관할 수 있어야 한다.
- 무료 API의 사용량 제한이나 장애가 제품의 핵심 결과를 막지 않도록 한다.
- 운세와 상담은 같은 adapter를 사용하더라도 별도 저장 범위와 privacy context를 가진다.
