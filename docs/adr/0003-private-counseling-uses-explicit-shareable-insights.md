# 프라이빗 상담은 사용자가 승인한 공유 힌트로만 커플 컨텍스트에 반영한다

프라이빗 상담 원문은 당분간 저장 시 암호화하지 않으며 서버 운영자와 DB 접근자가 운영 목적으로 확인할 수 있다. 대신 파트너와 일반 사용자 API에는 노출하지 않고, 공개 커플 상담 컨텍스트로 자동 이동하지 않는다. 사용자가 확인하고 공유를 승인한 추상화 정보만 공유 힌트로 저장하고 커플 컨텍스트에 포함한다. 이는 MVP 구현을 단순하게 하는 대신 저장 데이터 유출과 운영자 오남용에 취약한 보안 부채를 남긴다. 향후 저장 암호화와 운영자 접근 감사가 별도 보안 작업으로 필요하다.
