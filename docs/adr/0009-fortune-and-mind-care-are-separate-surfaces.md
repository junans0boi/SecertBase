# 운세와 마음관리는 관계 이해 허브에서 분리한다

홈의 `오늘의 운세` 카드에서 진입하는 운세 표면은 관계 이해 허브의 개인 탭과 분리한다. 운세는 사주와 타로를 통해 오늘 하루의 흐름을 자세히 살펴보는 자기성찰 콘텐츠이며, 같은 날짜와 콘텐츠 버전에서는 같은 결과를 보여준다. 예언·진단·치료를 약속하지 않고, 결과의 해석 기준과 사용한 출생 프로필 범위를 표시한다.

관계 이해 허브는 개인검사와 커플검사, 궁합 분석에 집중한다. 개인검사 4개와 커플검사 3개 모두 진행률, 완료일, 과거 기록, 새 검사, 최근 2회 차원별 변화 비교를 같은 정보 구조로 제공한다.

마음관리는 상담사 검색·예약·결제나 LLM 대화보다 선택지 중심의 감정 체크인과 작은 행동 제안을 우선한다. 사용자가 감정·상황·필요·행동을 선택하고 완료를 확인하는 흐름이며, 자유 입력과 선택적 자연어 보조는 부가 기능이다. 개인 마음관리 원문은 자동으로 파트너에게 공유하지 않는다.

자해·자살·폭력 위협·심각한 공황과 같은 위험 신호가 선택되면 일반 추천보다 상황별 안전 안내를 먼저 제공한다. 이 안내는 현재 안전 확인, 신뢰할 사람에게 연락, 지역 전문·응급 지원 연결을 제공하지만 진단·위험도 판정·자동 신고·파트너 자동 통보를 수행하지 않는다. 지역별 연락처와 안내 문구는 별도의 버전 있는 콘텐츠로 관리해야 한다.

## Consequences

- 운세의 독립 진입점과 관계 이해 허브의 정보 구조가 명확해진다.
- 운세·마음관리·검사 진행 상태가 한 화면에 섞여 사용자를 혼란스럽게 하지 않는다.
- 핵심 결과는 결정론적 콘텐츠와 고정 선택지로 동작하므로 LLM 없이도 이용 가능하다.
- 안전 안내 콘텐츠와 지역별 전문·응급 리소스는 출시 전 검토와 갱신 책임이 필요하다.
- 상담사 marketplace, 의료 진단, 자동 위기 개입, 파트너 자동 통보는 이 범위에서 제외된다.
