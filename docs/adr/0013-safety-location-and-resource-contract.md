# 안전 안내는 위치 권한과 버전 있는 지역 리소스를 사용한다

자해·자살·폭력 위협·심각한 공황 신호가 선택되거나 자유 입력에서 위험 가능성이
표시되면 일반 마음관리 콘텐츠보다 안전 확인을 먼저 보여준다. 순서는 현재 안전
확인, 즉시 도움, 신뢰할 사람, 전문·응급 리소스다. 시스템은 위험도를 자동 판정하거나
자동 신고·파트너 통보를 하지 않는다.

지역 리소스를 선택하기 위해 Flutter가 위치 권한을 요청한다. 허용되면 국가와
행정지역만 일시적으로 사용하고 정확한 좌표나 이동 이력은 저장하지 않는다. 권한을
거부하거나 위치를 얻지 못하면 일반 안전 안내만 제공한다. v1 리소스 카탈로그는
한국 행정지역별 버전 JSON과 출처·유효기간을 포함하며, 다른 지역은 일반 안내로
fallback한다. 리소스 문구는 코드 리뷰와 사람 검토를 거쳐 갱신한다.

## 구현 상태 (2026-09-10)

`safety-resources-kr.json`을 `safety-kr-v1` 버전·출처·유효기간과 함께 추가하고,
인증된 `GET /api/relationship/mindcare/safety-resources`가 권한·국가·행정지역만
받도록 구현했다. 좌표 query는 거부하고, 권한 거부·한국 외 지역·알 수 없는 행정지역은
일반 fallback으로 응답한다. 마음관리 안전 확인 API의 안전하지 않음 응답도 같은
고정 리소스 계약을 사용한다. Flutter의 `PlatformSafetyLocationProvider`가 권한·서비스·
역지오코딩 실패를 일반 fallback으로 축약하고, 안전 화면은 지역 기준 또는 일반 안내와
접근성 label을 표시한다. 위치 정보를 얻지 못해도 즉시 도움 문구는 중단되지 않는다.

## Consequences

- 안전 리소스는 현재 위치와 출생지를 혼동하지 않는다.
- 위치 권한이 없어도 안전 확인과 도움 요청 문구는 중단되지 않는다.
- 지역 리소스의 정확성은 버전과 출처로 추적할 수 있지만, 한국 외 지역의 v1 상세 번호는 제공하지 않는다.
