# 운세와 상담은 저장된 범위와 명시적 생성으로 확장한다

관계이해 기능은 출생 프로필을 매일의 개인 운세·감정 흐름과 활성 Couple의 관계 운세로 확장한다. 결과는 날짜, 콘텐츠 버전, 제공자·모델·프롬프트·컨텍스트 버전과 함께 저장하여 두 사람이 같은 커플 결과를 보고, 재생성은 사용자의 명시적 POST 요청으로만 허용한다. 출생 시각과 장소가 없더라도 콘텐츠를 막지 않으며, 결과는 사주 형식의 자기성찰 콘텐츠임을 표시한다.

상담은 private와 shared 세션을 별도 범위로 저장한다. private 원문은 소유자 API만 읽을 수 있고, shared 세션은 활성 커플의 양쪽만 읽을 수 있다. private 원문은 shared 컨텍스트로 자동 이동하지 않으며, 사용자가 확인해 승인한 추상화 힌트만 shared 컨텍스트에 포함한다. 현재 저장 암호화와 운영자 접근 감사는 적용하지 않아 DB 운영자는 원문을 볼 수 있다는 제한을 명시한다.

자연어 생성은 기존 provider adapter를 통해 선택적으로 수행한다. provider가 비활성화되거나 실패하면 결정론적 운세 콘텐츠와 고정 상담 응답을 반환한다. provider는 점수, 판정, 권한, 범위를 바꿀 수 없다.

## Consequences

- 운세와 상담은 REST 요청-완료 응답으로 먼저 제공하며, 스트리밍과 부분 응답 재개는 별도 결정으로 남긴다.
- Separation 중 shared 운세·상담은 차단되지만 private 상담은 소유자에게 남는다.
- 같은 두 사용자의 Reunion은 기존 Couple ID의 shared 기록을 복원한다.
- 무료 API를 설정하지 않아도 핵심 사용자 흐름은 fallback으로 동작한다.
- private 원문 암호화와 운영자 접근 감사는 출시 전 별도 보안 작업으로 추적해야 한다.
