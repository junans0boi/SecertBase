# 분석: MomentLoop + 비밀지도 (ML = lib/screens/archive/moment_loop_screen.dart, MAP = map_screen.dart)

## 0. 요약
구조는 탄탄하다(주간 피드, 업로드 아웃박스, 오늘의 루프 잠금/공개, 상태·감정 태그가 있는 핀, 길찾기). 그러나 첫 사용 안내가 없고, "지금 찍어서 올리기"(카메라)가 없으며, 출시 직전 빌드에 자리표시자 UI(가짜 하트/댓글)와 정책 위험(OSM 타일, 미사용 권한)이 남아 있다. 2.0 = 촬영 우선 진입 + 오늘의 루프 상단 고정 + 장소 추가 단순화 + 출시 정리.

## 2. 흐름(탭 수)
1. 첫 사용: MomentLoop 탭→빈 상태→순간 남기기→추가→갤러리→캡션→공유 = 5~6탭, 안내·권한 설명 없음. 지도 탭은 위치 권한을 즉시 요청(MAP:92).
2. 오늘의 루프: 홈 CTA는 탭 전환만(home_screen.dart:538)→FAB→선택→"오늘의 순간" 스위치(기본 OFF, ML:3336) 직접 켜기→공유 = 6탭 이상. 켜지 않으면 루프가 영영 완성되지 않고 경고 없음.
3. 푸시→상세→반응 = 2탭(좋음).
4. 장소 추가: 검색(엔터만)→결과→카드 "저장"→패널→"지도에 저장" = 5~6탭, FAB 추가는 이름 비어 있고 날것의 위경도 노출.
5. 기록에 장소 연결: 8탭 이상, 지도 모달에서 핀 추가 후 자동 선택되지 않음.
6. 다녀온 뒤: "오늘 다녀왔어요"가 11블록 상세의 맨 아래.

## 3. 문제점
상(출시 차단)
- S1 카메라 없음: pickMultipleMedia만 사용, `ImageSource.camera` 없음. MOMENTLOOP_PLAN Phase 2(촬영 우선)와 불일치.
- S2 영상 10초 제한을 업로드 후 서버에서만 확인(422). 클라이언트는 30MB만 확인. 임시저장 시트는 "업로드 실패 · n/m"만 보이고 오류 코드를 숨겨 같은 실패를 반복.
- S3 오늘의 루프 상태가 홈에만 있고 스위치 기본 OFF, 홈 CTA가 미리 켜 주지 않음.
- S4 지도: 409 active_couple_required/ok:false를 조용히 무시 → "아직 우리 지도가 비어 있어요"로 오표시. MomentLoop는 문구는 있으나 CTA 없음.
- S5 자리표시자 UI: "하트" 토스트만(저장 안 함), "댓글: 다음 연결에서 붙일게요", "공유"는 클립보드 복사만.
- S6 인프라/정책: OSM 공용 타일 서버(사용 정책 위험, 확인 필요), Nominatim 폴백이 제3자로 질의 전송, AndroidManifest에 미사용 CAMERA·RECORD_AUDIO·READ_MEDIA_* 선언(Play 심사 노출).
중
- M1 권한 시점/재생성: 위치를 initState에서 high 정확도로 요청, 탭 전환 시 페이지 재생성으로 지도 재로딩·MomentLoop의 주/태그/스크롤 소실.
- M2 "공유" 라벨이 공개 게시처럼 읽혀 "친밀함" 원칙과 충돌, 닫은 뒤 업로드 진행/성공 피드백 없음.
- M3 ⋮ 메뉴가 상대 글에도 "오늘의 순간"·"수정"을 보이고 삭제만 소유자 제한, 오류는 탭 후에 표시.
- M4 fetchFeed가 weekStart를 무시하고 전체 기록 로드, 하이라이트 스트립은 날짜 없이 "나/상대" 라벨만.
- M5 태그 필터 죽음: 태그 입력이 없고 항상 '#momentloop'.
- M6 장소 추가 마찰: 자동완성 없음, 저장 시 필터가 새 상태/카테고리로 바뀌어 다른 핀이 숨겨짐, 기본값 방문+별점 5.
- M7 장소 상세 과밀(11블록), 2인 비공개 지도에서 "리뷰"는 중복, 작성자가 raw user_code로 표시.
- M8 명칭/헤더 불일치: 지도/우리 지도/비밀 지도/비밀지도 위치/비밀 장소 추가, 헤더 BrandLogo vs MainTabHeader, 영어 "MomentLoop"·"Date Afterglow".
- M9 임시저장/저장소 오류 UI 무스타일, 빈 상태 없음.
하: 핀 클러스터링/fitBounds 없음, 지도 상단 오버레이 과밀, 위치 배너 닫기 불가, 접근성(아이콘 버튼 툴팁/시맨틱 없음, 18px 삭제 버튼, kMainMuted 대비 약 2.2:1, 11~12px 글자), 삭제 확인에 반응·댓글 소실 안내 없음, 상대 미연결/미작성 상태 없음.

## 4. 개선 제안
정보 구조
- MomentLoop 상단에 "오늘" 카드(TodayCard 재사용) 고정, 홈 CTA는 작성기를 "오늘의 순간 ON"으로 직접 열기.
- 피드 = 오늘 / 이번 주 / 지난 기록(월). 주 이동·달력·격자/목록 토글을 하나의 툴바로, 하이라이트는 "오늘"에 날짜·닉네임과 함께 흡수. 서버 범위 쿼리 `?from&to`(확인 필요).
- 작성기: 촬영 → 갤러리 → 글만 3개 액션, 캡션 한 줄, 위치/날짜/오늘은 접힌 "더 보기".
- 지도: 오버레이는 검색+내 위치만, 상태 칩 한 줄, 카테고리는 끝의 칩 하나, 목록은 시트 핸들, 하트/댓글/리뷰 제거 → "둘의 한마디"+연결된 추억.
- 명칭 통일: 탭 "기록"/"비밀지도", "리뷰"→"한마디", "Date Afterglow"→"다녀온 뒤의 이야기".
화면별
- 작성기: 카메라 우선(10초 진행 링), 클라이언트 영상 길이 검사+"앞 10초만 사용" 트리머, 버튼 "남기기"+"둘만 볼 수 있어요", 업로드 진행/성공/재시도 스낵바.
- 상세: 소유자 기준 메뉴, 댓글은 "댓글 N개" 요약 줄.
- 장소 추가: 디바운스 자동완성→미니 시트 하나(이름·카테고리 미리 채움, "다녀왔어요/가고 싶어요" 두 버튼), 별점·태그·메모는 나중에, 좌표 숨김, FAB="지도에서 위치 고르기"는 이름 필수.
- 장소 상세: 3섹션(요약+하단 고정 CTA 길찾기/다녀왔어요, 우리 이야기, 더보기), 공유는 시스템 시트+카카오+장소 카드 이미지.
- 양방향 연결: 새 핀 자동 선택, 핀 상세에서 "이 장소에서 순간 남기기".
빠진 화면: 첫 사용 가이드(2장), 사용 시점 권한 사전 안내 시트(위치/카메라·마이크/알림, 거부 시 설정 CTA), 미연결 전체 화면+초대 CTA, 오류 상태(피드, 지도 ok:false/타일/검색), 이유별 업로드 메시지("영상은 10초까지예요", "30MB 이하"), 파트너 대기 안내+콕 찌르기, 설정 연결(알림 시간, 위치 상태).
컴포넌트: MainTabHeader, TodayCard, MediaCaptureSheet, UploadStatusBanner, PermissionRationaleSheet, EmptyStateCard, StatusChip/CategoryChip, PlaceCard, SheetFrame, ErrorRetryState, PinMarker+범례.
