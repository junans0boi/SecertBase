# 분석: 관계 콘텐츠(타로·사주·운세·궁합·상담·마음관리·검사) + 상점
(rel/ = lib/screens/relationship/, shop/ = lib/screens/shop/, srv = services/realtime-server/src)

## 0. Top 3
1. **안전 구멍.** 서버는 상담 위기 시 "아래 도움 기관 안내도 확인해 주세요"와 리소스를 내려주지만(srv/routes.js:8060-8095) 앱 counseling_api/screen에는 safety/resources 처리가 없다. 마음관리는 "안전하지 않아요"를 누른 순간 위치 권한을 요청(mindcare_screen.dart:130-140). 리소스 API 실패 시 카드가 없고, 112/119/109가 앱에 내장돼 있지 않으며 연락처는 탭해도 전화·복사가 안 된다.
2. **막다른 길.** 홈은 `const SajuScreen()`·`const TarotScreen()`을 콜백 없이 연다. 사주 "출생정보 수정하기"가 `onPressed:null`(saju_screen.dart:150), 오류 상태에 버튼 없음, 타로는 파트너 연결 CTA 없음, 운세의 "이 흐름으로 상담 시작하기"는 콜백을 넘기는 곳이 없어 절대 안 보임.
3. **정보 구조 분산 + 뽑기 문제.** 운세·타로·사주·관계이해·마음관리·상담·궁합이 홈 캐러셀·홈 카드·더보기·허브 탭에 중복. 상점은 놀이 탭 pill에서만 진입. 뽑기는 확률 미공개, 가격 하드코딩(3,000/45,000/100,000), 확인 다이얼로그 제목이 흰 배경에 흰 글자.

## 2. 흐름
운세·타로 홈에서 1탭(사주는 스와이프+탭), 사주 첫 사용 3탭, 마음관리 2탭+선택 10회, 개인 검사 3탭+문항 N×2, 궁합 5탭, 상점 구매 4~5탭.

## 3. 문제점
상: (1) 상담 위기 응답이 앱에서 끊김 (2) 마음관리 위치 권한이 위기 순간에 뜸·고정 연락처 내장/전화 연결 없음 (3) 홈에서 연 사주·타로의 콜백 누락·운세→상담 CTA 죽음 (4) 뽑기 확률 미공개(법무 확인 필요)·가격 하드코딩·안 보이는 다이얼로그 (5) 상담·마음관리에 "AI이며 전문 상담/의료 아님" 고지 없음, 허브 카피는 "상담사와 채팅하듯", 외부 LLM 전송 동의 안내 없음(LLM_PROVIDER 기본 disabled면 고정 문구 반복).
중: (6) 용어·경로 중복("관계 이해 허브" 반복, 죽은 RelationshipEntryCard) (7) 심리검사 진입이 출생 프로필에 묶임, 가입 때 이미 받은 생일을 허브가 다시 묻고 홈/허브가 상태를 달리 판정 (8) 사주 제한 모드 버튼이 "네"(기획은 "제한된 정보로 보기") (9) 타로·사주·운세·궁합 공유/저장/복사 전무 (10) 타로 앞면이 아이콘+7px 영문 라벨, 22장 모두 정방향인데 "정방향" 라벨, 면책 11px (11) 운세 "SHA-256 해시" 설명이 기술적, 오류 CTA가 문자열 contains('파트너')에 의존 (12) 검사 1~5 칩에 라벨 없음, 카탈로그에 "후보 N문항·실제 M문항"·버전 노출, 척도 설명 없음 (13) 상점 잔액 중복, "구매 후 잔액 반영" 문구 불명, 인벤토리엔 마블 필터가 있고 상점엔 없음, 코인 획득 안내 없음 (14) 상점 오류 `오류: $e` 노출·재시도 없음·미션이 비면 영구 "불러오는 중..."·쿠폰 제목 비우면 무반응.
하: 8~11px 글자(상점·인벤토리·타로 7px), 이모지 아이콘, 흰/크림 혼재·이전 다크 테마 잔재, 프로필 폼 드롭다운 4개, 면책 문구·크기 제각각.
유지할 것: 하루 한 장 고정(같은 날 같은 결과), 사주 쉬운/전문 2단 보기, 검사 자동 저장·이어하기·이력 불변, 마음관리 비공개 고지, 서버 위험 표현 사전과 일반 안내 fallback.

## 4. 2.0 제안
IA: **하나의 "우리 이해(마음·운세)" 섹션**(더보기 행과 홈 진입을 여기로 통일). ① 오늘: 운세 한 줄+타로 한 장, 연결 시 "나/우리" 토글로 개인↔커플. ② 알아가기: 사주, 심리검사(개인·커플), 궁합, 상태 뱃지. ③ 돌봄: 마음관리, 상담(톤을 낮추고 항상 "도움이 필요하면" 칩, 상담은 마음관리 안으로 통합 검토).
출생 정보: 가입 생일 프리필, 사주·운세 첫 진입 시 바텀시트로 완성(양/음력, 시각 모름 건너뛰기), 검사에서는 프로필 요구 제거.
화면별: 운세·사주 공유 이미지 카드, 해시·버전은 접이식 "자세히", 제한 모드 "시각 없이 보기 / 정보 추가하기"+콜백 항상 연결, 프로필 수정 후 자동 재조회. 타로 큰 덱+뒤집기 연출+햅틱·카드별 일러스트·공유·면책 13px 이상. 검사 척도 설명·Likert 양 끝 라벨·"약 N분·N문항". 마음관리·상담(안전 최우선): 입장 시 1회 동의 시트(AI 가이드, 의료 아님, 비공유, 112/119/109), 고정 연락처 내장+탭하면 전화/복사, 위치는 사전 선택 토글(위기 시 즉시 일반 안내를 먼저 보여준 뒤 지역 정보로 보강), 서버 `safety` 필드와 리소스 카드 연결. 상점: 잔액 1곳, "코인 얻는 법", 더보기에서도 진입, 뽑기 확률 시트, 가격은 서버값, 다이얼로그 색 수정, 이모지→아이콘, 보유/장착 뱃지 통일, 인벤토리 필터를 상점 카테고리와 맞춤, 미션을 수령 가능/진행/완료로 구분.
빠진 화면: 관계 콘텐츠 소개, 출생정보 시트, 마음관리 동의, 오프라인 위기 안내, 파트너 미연결 빈 상태 공통, 스켈레톤, 오류 카드(원인 enum→CTA), 상점 오류·빈 미션·확률 시트.
컴포넌트: ResultCard(공유 포함), ScopeToggle, StatusFeatureCard, SafetyHelpChip/CrisisSheet, ConsentSheet, ErrorRetryCard, CoinPill, ShopItemCard, OddsSheet, ShareCardRenderer, LikertScale.
