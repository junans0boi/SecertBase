우리 이해 (마음·운세)

무엇이 달라지나요

  • 한 섹션으로 통합 — 홈 캐러셀·홈 카드·더보기·허브 탭에 흩어진 운세·타로·사주·관계 이해·궁합·검사·마음관리·상담을 ‘우리 이해’ 하나로 모아요. 오늘 → 알아가기 → 돌봄 순서이고, 연결 후에는 ‘나/우리’ 토글 하나로 개인↔커플을 오가요. (분석 문제 6)
  • 막다른 길 제거 — 사주 ‘출생정보 수정하기’(동작 없음)·오류 화면 버튼 없음·타로의 파트너 연결 안내 없음을 모두 살려요. 오류 화면에는 항상 다시 시도 + 정보 수정이 있어요. (문제 3)
  • 출생정보는 시트 한 장 — 가입 때 받은 생일을 미리 채우고, 양/음력·윤달·‘시각 모름’까지 한 번에 끝내요. 심리검사는 출생정보를 요구하지 않아요. (문제 7)
  • 사주 제한 모드 — ‘네’ 대신 시각 없이 보기 / 정보 추가하기. 보는 중에도 상단 안내와 추가 버튼이 남아요. (문제 8)
  • 공유·저장 — 운세·사주를 1:1 이미지 카드로 저장·공유해요. 이름·생일·네 기둥 글자는 카드에 넣지 않아요. (문제 9)
  • 읽기 쉬운 표현 — SHA-256 해시·버전은 ‘자세히’ 접이식으로, 타로는 큰 덱·뒤집기·카드별 일러스트(22장 직접 그림), 정방향 라벨 삭제. 검사는 1~5 양 끝 라벨 + ‘약 N분·N문항’. 면책은 13px 이상. (문제 10~12)

화면 구성 (27)

  • 홈: 연결 · 미연결(‘우리’ 잠금+연결 배너) · 로딩 · 오류(오늘 영역만 오류, 나머지 정상)
  • 출생정보 시트: 가입 생일 프리필 · 음력/윤달/시각 모름 · 오류
  • 운세: 기본 · 자세히(접이식) · 공유 카드 미리보기
  • 타로: 덱 · 뒤집기 · 결과 · 이미 뽑음(지난 카드)
  • 사주: 쉬운 · 전문 · 시각 선택 · 제한 모드 · 범위 밖 · 오류 · 공유 카드
  • 심리검사: 목록 · 진행 · 결과 · 파트너 대기 / 궁합: 목록 · 상세
  • 우리 이해 홈은 더보기·홈 바로가기에서 들어오는 하위 화면이라 하단 탭 없이 뒤로가기를 써요. ‘도움이 필요하면’ 칩은 홈 상단에 항상 보여요(→ 돌봄 탭 목업).
  • 사주 한자·오행 값은 화면 구성을 위한 예시예요.

승인받고 싶은 결정

  • 상담을 마음관리 안으로 통합할까요? 지금은 ‘마음관리’(고정 선택지)와 ‘상담’(AI 대화)을 돌봄에서 나란히 두었어요. 통합하면 입구가 하나로 줄고 동의·안전 안내를 한 번만 관리해요.
  • 운세·타로·사주 공유 카드를 허용할까요? 허용하면 이미지 저장·공유가 생겨요(개인정보는 카드에서 뺐어요). 타로 카드 이미지 공유는 가장 가벼운 범위부터 시작할 수도 있어요.
  • 검사 이력 비교(지난 결과와의 비교 한 줄)를 1.0 범위에 넣을까요? 목업에는 한 줄만 넣어 뒀어요.

구현 때 필요한 서버·정책 작업

  • 가입 생일 → birth-profile 프리필 API/마이그레이션. 두 값이 갈라지는 실제 케이스 확인 필요.
  • 사주 지원 범위(예: 1900~2100) 서버 확정 후 ‘범위 밖’ 문구에 반영. 확인 필요
  • 사주·운세 공유 카드 렌더러(1:1, 이름·생일 비포함 기본값) 및 허용 여부 정책.
  • 궁합 AI 설명이 외부 LLM으로 나갈 때의 전송 범위 고지(풀이 요약만 전송). 약관 확인 필요
  • 타로 22장 일러스트는 새로 그린 SVG(‘죽음’→‘끝과 시작’, ‘악마’→‘얽매임’, ‘심판’→‘부름’으로 이름을 순화). 카피 확인 필요.
  • 오류 원인을 enum(네트워크·출생정보 누락·범위 밖)으로 내려 문자열 비교 제거.
