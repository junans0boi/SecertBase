홈

"오늘 우리 둘의 순간이 어떤 상태인지"를 한눈에 보여 주고, 눌러서 바로 남기게 하는 홈이에요.

무엇이 달라지나요

  • 오늘 카드의 CTA가 작성기를 바로 열어요. 지금은 탭만 바뀌고 작성기는 안 열려서 4~5탭이 필요해요(분석 #1). "오늘의 순간" 스위치도 기본 ON이라 한 번에 홈 카드에 반영돼요.
  • 주 행동이 하나예요. 큰 "순간 남기기"·"놀이" 카드를 없애고(#2), 카드의 버튼만 상태에 따라 바뀌어요: 남기기 / 콕 찌르기 / 같이 보기.
  • 완성하면 실제 썸네일 두 장이 보이고, 상대 순간은 내가 남기기 전까지 잠겨 있어요(#6). 나만 남겼을 땐 "콕 찌르기"로 한 번에 재촉할 수 있어요.
  • 시작일 미설정과 조회 실패를 구분해요. 미설정이면 히어로가 "첫날 정하기"를 보여 주고 시트로 바로 가요(#3). 오늘 카드만 실패하면 그 카드만 오류로 바뀌고 나머지는 그대로예요(#7).
  • 알림 벨과 권한 거부 배너를 홈에 둬요(#4). 오프라인 경고는 장미색이 아닌 회색 줄이에요.
  • 바로가기는 4칸으로 줄이고(#16), 비밀기지 칸에 받을 보상 개수 뱃지를 달았어요. 모든 글자는 대비 4.5:1 이상, 터치 영역은 44px 이상이에요(#8, #9).

화면 구성

  • 홈 상태 10가지: 완성 · 나만 남김 · 상대만 남김 · 아직 안 남김 · 시작일 미설정 · 첫 사용 체크리스트 · 로딩 · 부분 실패 · 오프라인 · 알림 거부
  • 오늘의 루프 뷰어 6가지: 공개 연출 · 사진+글 · 영상 · 상대 삭제 · 대기 · 실패
  • 시작일 설정 시트(날짜 휠 + 오늘 기준 D+n 미리보기)
  • 순서는 히어로 → 오늘 카드 → 상대 상태 한 줄 → 바로가기 → "n년 전 오늘"이에요. 기록이 없는 날의 "n년 전 오늘"은 안내 카드로 대신해요.

승인받고 싶은 결정

  • 시작일을 연결 직후 자동으로 오늘로 채울까요? 자동으로 채우면 D+1부터 바로 보이고 첫 사용 체크리스트가 3개로 줄어요. 대신 실제 사귄 날과 다를 수 있어서 시트에서 바꾸도록 안내해요. (이 목업의 "첫 사용"은 자동 설정을 가정했어요)
  • 공개 연출은 한 번만 보여 줄까요? 둘이 완성한 날 처음 열 때만 보이고, 이후엔 바로 두 카드를 보여 줘요. 매번 보면 느리게 느껴질 수 있어요. "건너뛰기"는 항상 있어요.
  • 콕 찌르기는 하루 1번으로 제한해요(상대 알림 피로 방지). 괜찮을까요?

구현 때 필요한 서버·정책 작업

  • markViewed 호출: 뷰어가 열려 공개 연출이 끝나면 호출하고, 홈 카드의 "새로 도착" 점과 푸시 배지를 거기에 맞춰요. 지금은 호출처가 없어 viewed 상태에 도달할 수 없어요(#5). 뷰어를 Stateful로 바꿔요.
  • 시작일 자동 설정: 파트너 연결 시 StartDate가 비어 있으면 연결일로 채우는 정책이에요. 마일스톤은 COALESCE(StartDate, ActivatedAt)라 홈 D-day와 기준이 다를 수 있어서 같은 값을 쓰도록 통일해요(확인 필요).
  • 콕 찌르기 API(일 1회 제한, 푸시 payload)와 오늘 카드 응답에 썸네일 URL 포함.
  • 푸시 권한은 "첫 순간 남긴 뒤" 사전 안내 시트에서 요청하고, 거부 상태는 앱 복귀 시마다 다시 확인해 배너를 갱신해요.
  • 탭 전환 시 홈이 재생성되는지 확인하고(home_shell.dart:166), 캐시를 두어 오프라인에서도 마지막 카드를 보여 줘요.
