기록 (구 MomentLoop)

무엇이 달라지나요

  • 오늘 카드를 맨 위에 고정해요. 비어 있음 / 서윤 기다림 / 내 차례 / 완성 4상태를 한 카드에서 보여 주고, 눌러서 바로 작성기를 열어요. (S3: 기록 탭에서 오늘의 순간 상태를 볼 수 없던 문제)
  • 작성기는 촬영 · 갤러리 · 글 3개 액션만 남겨요. “오늘의 순간”은 기본 ON, 위치·날짜는 접힌 “더 보기”로 숨겨요. (S1 카메라 없음, M2 “공유” 오해 → “남기기 + 둘만 볼 수 있어요”)
  • 영상 10초를 올리기 전에 기기에서 검사하고 “앞 10초만 사용” 트리머를 제공해요. 실패는 이유별 문구(“영상은 10초까지예요”, “30MB 이하예요”)로 알려 줘요. (S2)
  • 피드는 오늘 / 이번 주 / 지난 기록 세그먼트 하나, 주 이동·달력·격자/목록은 한 줄 툴바로 합쳐요. (M4, M5: 죽은 태그 필터 삭제)
  • 상세는 글쓴이 기준 메뉴(내 글: 수정·삭제 / 상대 글: 저장·신고)와 “댓글 N개” 요약 줄, 반응 5개로 정리해요. 가짜 하트·“다음 연결에서” 문구 제거. (M3, S5)
  • 첫 사용 가이드 2장과 카메라·마이크 사전 안내 시트를 추가했어요. 새 핀은 위치 선택 시트에서 자동 선택돼요. (M6)

화면 구성

  • 메인: 오늘 비어 있음 · 서윤 기다림 · 내 차례 · 오늘 완성 · 목록 보기 · 지난 기록 · 빈 주 · 로딩 · 불러오기 오류 · 미연결 · 업로드 배너
  • 작성기: 기본 · 촬영 중 10초 링 · 첨부됨 · 10초 초과 트리머 · 입력 중 · 저장 중 · 저장 실패
  • 안내: 첫 가이드 2장 · 카메라/마이크 사전 안내 시트
  • 상세: 반응·댓글 · 내 글 메뉴 · 상대 글 메뉴 · 잠금 / 스토리 뷰어
  • 보조: 업로드 관리(대기·진행·실패 이유 / 빈) · 위치 선택 시트 · 달력 시트

승인받고 싶은 결정

  • 오늘의 순간 기본 ON으로 둘까요? (둘 다 남기는 비율은 오르지만, 가벼운 기록도 모두 “오늘의 순간”이 돼요. 작성기에서 끌 수 있어요.)
  • 댓글을 이번 출시에 넣을까요? 넣으면 상세에 “댓글 N개” 줄과 입력창이 필요하고, 빼면 반응 5개만 남겨요.
  • 10초가 넘는 영상은 자동으로 앞 10초만 쓰는 트리머(시안)로 할까요, 아니면 거절만 할까요?

구현 때 필요한 서버·정책 작업

  • 카메라 권한 정리: 지금 AndroidManifest에 선언만 된 CAMERA·RECORD_AUDIO·READ_MEDIA_*를 촬영 기능 도입에 맞춰 실제 사용 권한으로 정리하고, Play 심사용 사용 목적 문구를 맞춰야 해요. iOS는 NSCameraUsageDescription·NSMicrophoneUsageDescription 추가.
  • 피드 범위 쿼리: GET /api/setlog에 from/to(주·월 범위) 지원이 필요해요. 현재는 weekStart를 무시하고 전체를 내려받아요. (확인 필요)
  • 영상 길이 클라이언트 검사: 업로드 전에 길이·용량(30MB)을 검사하고 서버 422 코드를 이유별 문구로 매핑. 트리머는 기기에서 잘라 올려요.
  • 오늘의 순간 “콕 찌르기” 푸시와 일일 1회 제한, 업로드 아웃박스 실패 사유 코드 저장.
