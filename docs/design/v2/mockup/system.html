디자인 시스템

무엇이 달라지나요

  • 색 대비 복구 — 흰 바탕에서 muted #ABABBC 2.26, rose #FF6F9F 2.62, sage 2.28, honey 1.66 등이 모두 AA(4.5) 미달이었어요(분석 §3-10). 글자·버튼은 muted #6B6B84(5.17), rose-600/700, 칩은 한 단계 진한 글자색으로 바꿔요. 원색은 장식·그라데이션에만 써요.
  • 타입 6단계 — 지금은 title 22/20/24/26/28, body 13/12/14/11/15가 뒤섞여 있어요(§4). 28·22·18·15·13·12로 고정하고 본문 최소 13px, 라벨 12px, 11px 이하는 없애요.
  • 반경·간격 토큰 — 반경 12/20/28/pill, 간격 4pt(§4). 버튼 높이 50/52/56과 입력 스타일 4종은 52px 하나로 통일해요.
  • 컴포넌트 단일화 — AlertDialog 28곳·바텀시트 23곳·스낵바 50곳·AppBar 37곳을 직접 만들던 것을 시트·다이얼로그·스낵바·상단 바 3종으로 모아요(§3-16, 17).
  • 탭바 — 5탭 모두 한글, 선택은 장미색+위 막대, 뱃지·오프라인 규칙까지 정의해요(§3-8, 3-9).
  • 카피 톤 — “~해요” 통일, “상대의 이름 또는 우리”, 영어·개발 용어 금지(§3-11, 3-18).
