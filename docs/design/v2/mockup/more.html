  • 알림 설정 보강. 스위치 4개 + 방해금지 시간, 휴대폰 알림이 꺼져 있으면 안내 배너 + 설정 이동, 로드 실패는 재시도, 로딩은 스켈레톤. (§3-15)
  • 개인 보관함. 누가 볼 수 있는지 안내, 삭제 전 확인 시트(파일까지 지워짐), 내보내기 진행·완료·실패, 빈 상태 CTA, 연결 후 접근은 오류가 아니라 안내로. (archive §3-5)
  • 카피는 해요체, 오류에는 $e 같은 내부 문자열을 쓰지 않아요.

승인받고 싶은 결정

  • 탈퇴의 안전한 선택지를 크게? 탈퇴 1~2단은 "그만두기"를 주 버튼, "계속 탈퇴하기"를 글자 버튼으로 뒀어요. 마지막 단계만 빨간 "탈퇴하기"가 주 버튼이에요. 이대로 갈까요, 아니면 전 단계 동일 비중으로 할까요?
  • 더보기에 상점을 노출할까요? 놀이 탭 pill 외에 "우리 이야기" 안에 상점 행(코인 잔액 표시)을 넣었어요. 놀이 탭만으로 충분하면 한 줄을 빼면 돼요.
  • 연결 후 개인 보관함 정책. 지금 서버는 연결 후 접근을 막아요(409). 화면은 "닫혀 있어요, 기록은 지워지지 않아요"로 안내하는데, 연결 시 기록을 공유 기록으로 옮길지/계속 비공개로 둘지 정해 주세요.
  • FAQ와 문의: 문의 이메일이 비어 있는 동안은 문의 카드를 숨겨요. 출시 전에 채울지 알려 주세요.

구현 때 필요한 서버·정책 작업

  • 탈퇴 API를 연결 전 사용자에게도 열기 — 지금은 더보기→내 공간 경로뿐이라 파트너 대기 상태에서 도달 불가(Play 계정 삭제 요건). 서버 삭제 API는 커플 유무와 무관하게 동작하는지 확인.
  • Google 동의 이력 — 개인정보·권한의 "동의 내역"은 동의 일시를 서버에 저장해야 보여줄 수 있어요(현재 필드 없음, Google 가입은 동의 절차 자체가 없음).
  • 개발자 정보 빈 필드 — supportEmail, legalOperatorName이 비어 있어 앱 정보에서 해당 줄과 고객센터 문의 카드를 숨겨요. 소유자가 채우면 자동 노출(화면 "앱 정보(값 채움)" 참고).
  • 점검/강제 업데이트: 서버가 최소 버전·점검 창을 내려주는 엔드포인트가 필요해요(현재 없음). 진단 화면은 릴리스 빌드에서 7탭 해제만 가능하게.
  • 설정 API 호출을 ApiClient 경유로 변경(401·타임아웃 처리), 알림 항목 4종 서버 필드 추가, OS 알림 권한 상태 읽기.
