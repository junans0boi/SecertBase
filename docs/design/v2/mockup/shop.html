상점 · 인벤토리

무엇이 달라지나요

  • 잔액은 한 곳(CoinPill). 상단 오른쪽 코인 알약 하나만 남기고(티켓·코인 중복 표시 삭제), 누르면 "코인 얻는 법"이 열려요. 코인 획득 안내가 없던 문제 해결. (분석 §3-13)
  • 카테고리 통일. 상점과 내 아이템이 같은 필터(전체·윷·스티커·보석)를 쓰고, 보유 중 / 장착 중 뱃지는 모든 화면에서 같은 모양·색·글자예요. 등급(일반·희귀·특별·전설)은 색 + 글자로 같이 표시해요.
  • 뽑기: 확률 공개 + 서버 가격. 3티어 모두 확률 시트(등급별 %, 합계 100%)를 열 수 있고, 가격은 서버 값을 그대로 보여줘요(하드코딩 3,000/45,000/100,000 제거). 확인 다이얼로그는 흰 배경에 흰 글자였던 것을 잉크색 글자로 고쳤고, 뽑기 전후 코인을 보여줘요. (§3-4, §3-13)
  • 모든 상태가 있어요. 로딩(스켈레톤), 오류+다시 시도(오류: $e 제거, "코인은 쓰이지 않았어요" 안내), 코인 부족(부족분·진행바·코인 얻는 법 CTA), 구매·뽑기 성공/실패. (§3-14)
  • 미션을 세 덩어리로. 받을 수 있어요 / 진행 중 / 완료. 비어도 영구 "불러오는 중"이 아니라 빈 상태가 나와요. 데이트 쿠폰은 이름·기한이 잘못되면 칸 아래에 이유를 보여줘요(예전엔 무반응).
  • 아이템 그림은 모두 원본 SVG(보석·스티커·윷 막대), 이모지 아이콘 없음, 최소 글자 12px, 터치 영역 44px 이상.

승인받고 싶은 결정

  • 뽑기 확률 공개 수준. 목업은 "티어별 등급 확률 + 같은 등급 안은 균등"까지 보여줘요. 아이템 하나하나의 확률까지 공개할까요, 등급 단위로 충분할까요? (법무 확인 필요)
  • 더보기에 상점을 노출할까요? 지금은 "우리 이야기" 안에 상점 행과 코인 잔액을 넣었어요(놀이 탭 pill 외 두 번째 진입). 놀이 탭만 두려면 한 줄을 빼면 돼요.
  • 특별·전설 아이템은 뽑기 전용으로? 상점에서는 일반·희귀만 팔고, 특별·전설은 뽑기에서만 나오게 그렸어요. 상점에서 직접 살 수 있게 열지, 뽑기 전용으로 둘지 정해 주세요. 중복으로 뽑았을 때(코인 환급·교환)도 정책이 필요해요.

구현 때 필요한 서버·정책 작업

  • 티어 목록·가격·등급별 확률·마지막 갱신일을 내려주는 API(확률 시트와 실제 추첨이 같은 값을 쓰도록 단일 소스). 중복 결과 정책 필드.
  • 구매·뽑기는 원자적으로(코인 차감과 아이템 지급이 한 번에), 같은 요청 재전송에 중복 차감 없도록 멱등 키. 그래야 "실패해도 코인은 쓰이지 않았어요" 문구가 사실이에요.
  • 코인 획득 경로(미션 보상, 놀이 보상) 목록 API 또는 고정 문구 확정. "돈으로 살 수 없음" 문구는 현금 결제가 없다는 전제예요(Play 결제 심사와 연결).
  • 미션 상태 3종(수령 가능/진행/완료)과 일괄 수령, /missions 기능 게이트 해제 확인. 쿠폰 작성 검증은 서버도 같은 규칙(이름 1~20자, 기한은 오늘 이후)으로.
  • 잔액 표시는 한 곳에서만 가져오도록 상태 단일화, 로드 실패 시 "–" 표시.
