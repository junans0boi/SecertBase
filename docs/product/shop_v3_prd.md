# PRD: Shop v3 — 인벤토리 분리 + 카테고리 가챠 v2 + 아이템 확장

작성일: 2026-08-01  
상태: 승인됨 (그릴링 완료)

---

## 1. 문제

현재 상점은 구매/장착/가챠가 한 화면에 혼재돼 있어:
- "내가 뭘 가지고 있는지" 파악이 어려움
- 가챠가 단일 티어, 카테고리 구분 없어 게임별 수집 동기 부족
- 아이템이 16개뿐이라 뽑을 것이 없어 경제 시스템이 공허함
- 스탯이 DB에만 존재, 실제 게임에 반영 안 됨

---

## 2. 해결 방향

### 2-1. 화면 역할 분리
| 탭 | 역할 |
|----|------|
| 상점 | 아이템 목록 + 구매만. 장착 불가 |
| 인벤토리 | 보유 아이템 + 장착 + 카테고리 가챠 + 도감 |

### 2-2. 인벤토리 필터
- 상단 칩: **[전체 | 윷놀이 | 원카드]**

### 2-3. 가챠 v2 — 3티어 카테고리별

| 티어 | 가격 | B | A | S | SS | SSS |
|------|------|---|---|---|----|-----|
| 랜덤 뽑기 | 3,000금 | 60% | 37% | 3% | — | — |
| 고급 뽑기 | 45,000금 | — | — | 80% | 18% | 2% |
| 레어 뽑기 | 100,000금 | — | — | — | 96% | 4% |

- 선택한 카테고리의 아이템만 뽑힘
- 천장 없음 (초기 희소성 유지)
- 중복: `owned_items.quantity` 증가 (합성 시스템 인프라 준비)

### 2-4. 아이템 확장
- 총 50개 사전 제작 (`active=0`), 업데이트마다 2개씩 공개
- 현재 16개 active=1 유지

| 슬롯 | B | A | S | SS | SSS |
|------|---|---|---|----|-----|
| yut_yut | 4 | 4 | 4 | 3 | 3 |
| yut_piece | 4 | 4 | 4 | 3 | 3 |
| onecard_cardback | 3 | 3 | 3 | 3 | 2 |

### 2-5. 전용 스탯 12개 추가

**윷(yut_yut) 전용**
| 키 | 효과 |
|----|------|
| `yut_mo_rate_pct` | 모(5칸) 결과 확률 증가 |
| `yut_backdo_shield_pct` | 뒤도를 도(1칸)으로 변환 확률 |
| `yut_win_coin_pct` | 윷/모 나올 때마다 추가 코인 |
| `yut_overturn_pct` | 지고 있을 때 윷/모 확률 증가 |

**말(yut_piece) 전용**
| 키 | 효과 |
|----|------|
| `piece_catch_resist_pct` | 잡힐 확률 감소 |
| `piece_catch_coin_bonus` | 상대 말 잡을 때 추가 코인 |
| `piece_safe_zone_pct` | 시작점/모서리 착지 확률 증가 |
| `piece_group_pct` | 업은 말 분리 방지 확률 |

**원카드(onecard_cardback) 전용**
| 키 | 효과 |
|----|------|
| `card_shield_pct` | 상대 공격카드(+2/스킵) 무효화 확률 |
| `card_lucky_draw_pct` | 뽑기 시 원하는 카드 나올 확률 |
| `card_uno_protect_pct` | 원카드 선언 후 공격받지 않을 확률 |
| `card_reverse_bonus` | 리버스/스킵 사용 시 추가 코인 |

### 2-6. 도감
- 도감 버튼 → 전체 아이템 목록 다이얼로그
- 미공개(`active=0`): 실루엣 + "???" 표시
- 미보유 공개 아이템: 이름/아이콘, 스탯 잠금
- 보유 아이템: 스탯 미리보기

### 2-7. 게임 내 상대 아이템 표시
- 게임 시작 시 양쪽 플레이어의 장착 아이템 전달
- 게임 화면 상단에 양쪽 아이템 뱃지 표시
- 탭 시 스탯 요약 팝업

### 2-8. 가챠 애니메이션
- B/A: 즉시 결과 다이얼로그
- S: 별 파티클 + 파란 빛 버스트 (1.5초)
- SS: 보라 빛 + 카드 플립 × 3 + 파티클 (2.5초)
- SSS: 황금 + 무지개 글로우 + 카드 플립 × 5 + 폭발 이펙트 (3.5초)

## 3. DB 변경사항

### owned_items
```sql
ALTER TABLE owned_items ADD COLUMN quantity INT NOT NULL DEFAULT 1;
-- UNIQUE KEY (user_id, item_id) 유지
-- 중복 시: ON DUPLICATE KEY UPDATE quantity = quantity + 1
```

### item_stats.stat_key ENUM 확장
기존 10개 → 22개 (12개 추가)
