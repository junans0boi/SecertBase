# SecretBase 마블 — 게임 설계 문서 (GDD)

> **레퍼런스**: 모두의 마블 (Modoo Marble) — 참고만, 복사 아님  
> **목적**: 이 문서가 구현의 단일 진실 소스(Single Source of Truth)  
> **최종 결정일**: 2026-08-08

---

## 1. 게임 정체성

### 한 줄 정의
> "2인이 빠르게 땅을 사고 뺏으며 상대를 파산시키는 10~15분 마블 대전"

### 핵심 차별점 (vs 모두의 마블)

| 항목 | 모두의 마블 | 우리 게임 |
|------|-----------|---------|
| 인원 | 2~4인 | **2인 고정** |
| 플레이 타임 | 30~60분 | **10~15분** |
| 보드 크기 | 32~40칸 | **24칸** |
| 건물 단계 | 5단계 | **3단계** |
| 세계관 | 실제 세계 도시 | **SecretBase 테마** |
| 화폐 명칭 | 마블 | **마블머니 (MM)** |

### 타겟
- SecretBase 플랫폼 이용자
- 2인이 같이 하는 가벼운 대전 게임
- 복잡한 룰 없이 직관적으로 플레이 가능

## 2. 화폐 시스템

### 게임 내 화폐: 마블머니 (MM)
- 약칭 `MM`, 표기 예시: `500만 MM`
- 도시 구매, 건물 건설, 통행료 납부, 인수 등 모든 경제 활동에 사용
- 게임 종료 후 소멸 (SecretBase 골드로 전환 안 됨)

### 보상 화폐: SecretBase 골드
- 게임 **승리 시** 획득
- 독점 종류에 따라 배수 보너스 (상세: §7 승리 조건)
- 실제 SecretBase 경제 시스템에 연동

## 4. 칸 타입 상세

### 4-1. 도시 칸 (일반 부동산)

**구매**: 도착 시 주인 없으면 **땅만** 구매. 첫 구매에는 집 건설 불가.  
**건설**: 해당 도시에 **재방문할 때마다** 1단계씩 건설 가능 (방문당 1회 제한)  
**통행료**: 상대가 내 도시에 도착하면 지불 (땅만 있어도 통행료 발생)

### 4-2. 관광지 칸

**비밀의 섬** / **비밀의 해변**

- 구매 가능, 건물 단계 없음
- 두 관광지 모두 소유 시 → **관광지 독점** 즉시 승리
- 통행료: 고정 금액 (단계 없음)
- **인수 불가**

### 4-3. 특수 칸 상세

#### 임무 개시 (START, 칸 #0)
- 게임 시작 위치
- 경유 시: **월급 100만 MM** 지급
- 착지 시: 월급 100만 MM + 원하는 내 도시에 건물 1개 무료 건설

#### 블랙사이트 (격리구역, 칸 #6)
- 착지 시 **3턴 동안 이동 불가**
- 탈출 방법:
  1. 차례에 **더블** 나오기
  2. **탈출비** 50만 MM 지불
  3. **블랙사이트 탈출 작전카드** 사용

#### 운영본부 (세금, 칸 #12)
- 착지 시 **운영비 50만 MM** 지불 (은행)
- 마블머니 부족 시 건물 매각 후 납부

#### 비밀 게이트 (이동, 칸 #18)
- 착지 시 **이동 비용 50만 MM** 지불
- 다음 내 차례에 주사위 없이 **원하는 칸으로 직접 이동**
- 임무 개시 경유 시 월급 지급
- 비용 없으면 이동 불가 (그냥 다음 턴에 정상 진행)

## 5. 건물 시스템

### 건물 4단계

```
[땅] → [집] → [빌딩] → [랜드마크]
```

| 방문 횟수 | 할 수 있는 것 | 단계 |
|---------|------------|------|
| 1번째 방문 | 땅 구매만 가능 | 0 — 땅 |
| 2번째 방문 | 집 건설 가능 | 1 — 집 |
| 3번째 방문 | 빌딩 건설 가능 | 2 — 빌딩 |
| 4번째 방문 | 랜드마크 건설 가능 | 3 — 랜드마크 → **인수 불가** |

### 건물 건설 핵심 규칙
- **방문당 1단계만** 건설 가능 (한 번 방문에 여러 단계 건설 불가)
- **반드시 그 도시에 착지해야** 건설 가능 (원격 건설 불가, 임무개시 착지 특수 보너스 제외)
- 임무 개시(START) 착지 시: 내 도시 1곳에 한해 1단계 건설 보너스
- **작전 카드 "긴급건설"**: 방문 없이 1단계 건설 (카드 설명 §10 참고)
- 건설비 즉시 지불, 취소 불가

## 6. 경제 수치

### 시작 자금
- 각 플레이어: **500만 MM**

### 월급
- 임무 개시 경유: **100만 MM**

### 도시 가격표

| 등급 | 도시 | 구매가 | 집 건설 | 빌딩 건설 | 랜드마크 건설 |
|------|------|:----:|:----:|:----:|:----:|
| 레드 (저가) | 방콕, 카이로 | 50만 | 20만 | 50만 | 100만 |
| 오렌지 (저가) | 뭄바이, 자카르타 | 70만 | 30만 | 70만 | 140만 |
| 그린 (중가) | 시드니, 베를린, 모스크바 | 100만 | 40만 | 100만 | 200만 |
| 블루 (중가) | 도쿄, 상하이 | 130만 | 60만 | 130만 | 260만 |
| 퍼플 (고가) | 뉴욕, 파리 | 160만 | 80만 | 160만 | 320만 |
| 골드 (최고가) | 런던, 두바이, 서울 | 200만 | 100만 | 200만 | 400만 |

### 통행료표

| 단계 | 레드 | 오렌지 | 그린 | 블루 | 퍼플 | 골드 |
|------|:---:|:----:|:---:|:---:|:---:|:---:|
| 땅만 | 2만 | 3만 | 5만 | 7만 | 9만 | 12만 |
| + 집 | 8만 | 12만 | 18만 | 25만 | 32만 | 45만 |
| + 빌딩 | 25만 | 38만 | 55만 | 78만 | 100만 | 140만 |
| + 랜드마크 | 70만 | 100만 | 150만 | 210만 | 270만 | 380만 |

> 컬러 독점 달성 시 통행료 **2배**

### 관광지 통행료

| 관광지 | 통행료 |
|--------|:----:|
| 비밀의 섬 | 80만 |
| 비밀의 해변 | 80만 |

### 인수 비용
- **건설가 합계의 2배** 지불
- 랜드마크 있는 도시 → 인수 불가
- 관광지 → 인수 불가

### 특수 칸 비용
| 칸 | 비용 |
|----|:---:|
| 운영본부 (세금) | 50만 MM |
| 비밀 게이트 이용 | 50만 MM |
| 블랙사이트 탈출 | 50만 MM |

### 매각 (건물 처분)
- 매각가 = 건설비의 **절반**
- 통행료 납부 불가 시 건물 강제 매각 선택
- 전부 매각해도 부족 → **파산**

## 7. 승리 조건

### 즉시 승리 (독점)

| 독점 종류 | 조건 | 골드 배수 |
|---------|------|:-------:|
| **더블 독점** | 컬러 독점 2개 이상 | ×3 |
| **라인 독점** | 한 사이드(5칸) 도시 전부 소유 | ×4 |
| **관광지 독점** | 비밀의 섬 + 비밀의 해변 모두 소유 | ×5 |

> 컬러 독점 1개만으로는 통행료 2배 효과, 즉시 승리 아님

### 파산 승리
- 상대가 파산 → 즉시 승리
- 골드 배수: ×2

### 시간/턴 초과
- 제한시간 **15분** 또는 **30턴** 먼저 도달 시
- **총자산** 높은 플레이어 승리
- 총자산 = 보유 MM + (소유 건물들의 건설가 합산)
- 동점 시 → 무승부 (골드 없음)

## 8. 주사위 시스템

### 기본 굴리기
- 주사위 **2개** 동시 굴리기
- 눈 합계만큼 전진
- **더블** (두 주사위 동일) → 한 번 더 굴리기 가능
- **3연속 더블** → 블랙사이트 즉시 이동 (패널티)

### 게이지바 컨트롤
- ROLL 버튼을 **꾹 누르면** 반원형 게이지 애니메이션 시작
- **떼는 타이밍**에 따라 주사위 눈 범위 확률 증가:

| 게이지 구간 | 높은 확률 눈 |
|-----------|:----------:|
| 0~25% | 2~4 |
| 25~50% | 5~7 |
| 50~75% | 8~10 |
| 75~100% | 11~12 |

> 확률 증가일 뿐, 완전한 고정 아님 (랜덤 요소 유지)

### 홀/짝 버튼
- 기본 **잠금 상태** — 아이템 구매 후에만 사용 가능
- 아이템 구매처: **💎 아이템칸** 착지 시 구매 (가격: 홀예측권 100만 MM / 짝예측권 100만 MM)
- 아이템 보유 시 ROLL 전 홀 또는 짝 선택 가능
- 맞추면 → 다음 통행료 납부 시 **30% 감면** (1회성)
- 틀리면 → 아이템만 소모, 효과 없음
- 아이템은 최대 3개까지 보유 가능

### UI 배치
```
        [홀]   [ROLL]   [짝]
```
- 홀/짝: 파란 원형 버튼 (ROLL 좌우)
- ROLL: 빨간 원형 버튼 (가장 크게)

## 9. 선 정하기

### 포춘카드 선택 (실시간 방식)
1. 게임 시작 시 앞면이 보이지 않는 카드 **4장** 표시
2. 각 플레이어가 **동시에(독립적으로)** 카드 1장 선택
   - 내가 선택하면 → "상대 선택 대기 중..." 표시
   - **5초 내에 선택 안 하면** → 랜덤 자동 선택 (선착순)
   - 상대가 이미 선택한 카드는 선택 불가 (회색 처리)
3. 둘 다 선택 완료 → 자동으로 카드 공개
4. **높은 숫자** 카드를 뽑은 플레이어가 선 (1번 플레이어)
5. 동점 시 재추첨

## 10. 작전 카드 (찬스카드)

보드 4곳의 작전 카드 칸 도착 시 덱에서 1장 뽑기.  
카드는 뽑는 즉시 효과 발동 (보관 카드 없음, 단 방어카드 제외).

### 카드 목록 (총 15종)

#### 골드 카드 (유리한 효과)
| 카드 이름 | 효과 |
|---------|------|
| **임무 보너스** | 다음 임무 개시 통과 시 월급 2배 (200만 MM) |
| **긴급 지원금** | 상대에게 50만 MM 받기 |
| **통행료 면제증** | 다음 1회 상대 도시 통행료 면제 |
| **비밀 게이트** | 비밀 게이트 칸으로 이동, 다음 턴 원하는 칸으로 |
| **인수 할인권** | 다음 인수 비용 50% 감면 (1회) |
| **방어막** | 보관 가능. 상대의 공격/인수 1회 방어 |

#### 실버 카드 (중립/상황적 효과)
| 카드 이름 | 효과 |
|---------|------|
| **임무 개시로** | 임무 개시 칸으로 이동, 월급 지급 |
| **50% 할인** | 내가 원하는 도시 1곳 통행료 50% 감면 (다음 1회) |
| **블랙사이트 탈출** | 보관 가능. 블랙사이트 갇혔을 때 즉시 탈출 |
| **건물 긴급건설** | 내 도시 1곳에 턴 제한 무시하고 1단계 건설 |

#### 브론즈 카드 (불리한 효과)
| 카드 이름 | 효과 |
|---------|------|
| **블랙사이트 수용** | 즉시 블랙사이트로 이동 |
| **긴급 운영비** | 운영비 50만 MM 은행 납부 |
| **자산 이전** | 내 도시 1곳 (랜드마크 제외)을 상대에게 반환 |
| **도시 교환** | 내 도시 1곳 ↔ 상대 도시 1곳 교환 (랜드마크 제외) |
| **도시 파괴** | 상대 도시 1곳의 건물 1단계 하향 (랜드마크 제외) |

> 보관 카드 (방어막, 블랙사이트 탈출): 손에 1장씩만 보관 가능  
> 나머지: 즉시 발동 후 덱 하단으로

## 11. 프로필 카드 UI

### 레이아웃 원칙
- **상대** 프로필: 화면 상단, 캐릭터 왼쪽
- **본인** 프로필: 화면 하단, 캐릭터 오른쪽

### 상대 프로필 (상단)
```
┌────────────────────────────────────┐
│ [캐릭터]  닉네임           [순위]  │
│  (좌)    총자산: 000만 MM          │
│          보유MM: 000만 MM          │
│          [게이지바──────────────]  │
└────────────────────────────────────┘
```

### 본인 프로필 (하단)
```
┌────────────────────────────────────┐
│ [순위]  닉네임            [캐릭터] │
│         총자산: 000만 MM   (우)    │
│         보유MM: 000만 MM           │
│         [게이지바──────────────]   │
└────────────────────────────────────┘
```

### 표시 항목 정의

| 항목 | 정의 | 업데이트 시점 |
|------|------|------------|
| **닉네임** | 플레이어 이름 | 고정 |
| **보유MM** | 현재 보유 마블머니 현금 | 실시간 |
| **총자산** | 보유MM + 소유 건물들의 건설가 합산 | 실시간 |
| **순위** | 총자산 기준 1위/2위 | 실시간 |
| **게이지바** | 행동 제한시간 타이머 (인수/건설 결정) | 행동 시 카운트다운 |
| **캐릭터** | SecretBase 인벤토리에서 장착한 캐릭터 초상화 (인간형) | 고정 |

### 순위 뱃지
- 원형 뱃지, 크고 눈에 띄게
- 1위: 골드 배경
- 2위: 실버 배경

## 13. 파산 처리

1. 통행료/운영비/인수비를 낼 수 없을 때
2. **매각** 가능한 건물 선택 (매각가 = 건설비의 절반)
3. 매각 후에도 납부 불가 → **파산**
4. 파산 플레이어: 보드에서 제거, 도시 모두 반환 (빈 칸으로)
5. 상대방 즉시 승리

## 14. 캐릭터 시스템

### 연동 구조
- 캐릭터 선택/변경은 **SecretBase 인벤토리·상점**에서만 가능
- 마블 게임 내 캐릭터 선택 화면 **없음**
- 게임 진입 시 플레이어의 `equippedCharacter` 값을 그대로 사용

### 게임 내 사용처
| 위치 | 표시 방식 |
|------|---------|
| 프로필 카드 (상단/하단) | 캐릭터 초상화 (원형 크롭) |
| 보드 위 피스 | 캐릭터 얼굴 원형 토큰 (22px, 색상 테두리로 나/상대 구분) |
| 선 정하기 화면 | 좌우에 캐릭터 초상화 배치 |
| 결과 화면 | 캐릭터 초상화 + 닉네임 |

### 피스 토큰 색상 규칙
- 내 피스: 파란 테두리 (`#4a9eff`)
- 상대 피스: 빨간 테두리 (`#f07050`)
- 같은 칸 위치 시: 겹쳐서 표시 (내 피스가 위)

### 데이터 요구사항
```dart
// 게임 진입 시 필요한 캐릭터 데이터
class CharacterInfo {
  final String id;
  final String name;
  final String portraitUrl; // 인벤토리에서 장착된 캐릭터 이미지
}
```
