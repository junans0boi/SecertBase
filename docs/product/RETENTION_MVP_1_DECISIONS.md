# Retention MVP 1 결정 기록

상태: 확정, 구현 진행 중

근거 문서: [2026 커플 앱 리텐션 리서치](./2026_COUPLE_APP_RETENTION_RESEARCH.md)

## 확정 결정

### 1. 코어 MVP와 분리한다

Retention MVP 1은 2026-07-15 승인 코어 MVP를 다시 여는 작업이 아니다. 코어 MVP의 인증, Pairing, 개인정보 보호, Archive 안전성, 공개 기능 범위를 유지한 채 그 위에서 반복 사용 루프만 검증한다.

### 2. 첫 신규 기능은 `오늘의 순간`으로 제한한다

각 사용자의 오늘 기록을 두 사람의 `오늘의 루프`로 만드는 경험만 먼저 검증한다. 장소 연결은 기존 Secret Map 기능을 활용하며 선택 사항으로 유지한다.

다음 기능은 Retention MVP 1의 첫 구현에서 제외한다.

- 데이트 애프터글로우
- 과거 장소·MomentLoop 회고
- 우리의 비밀기지 성장
- 월간 기지 엽서

### 3. 자유 기록과 대표 기록을 분리한다

기존 MomentLoop는 하루에 여러 개 자유롭게 남길 수 있다. 각 사용자는 그중 기존 기록 하나를 선택하거나 새로 작성해 하루 최대 한 개를 `오늘의 순간`으로 지정한다. 두 사람의 `오늘의 순간`이 `오늘의 루프`를 구성하며, 선택되지 않은 MomentLoop도 기존 Archive와 Secret Map에 그대로 남는다.

### 4. 상호 기여 또는 보상형 광고로 공개한다

상대의 `오늘의 순간`이 먼저 등록되면 내용 대신 등록 사실만 보여준다. 사용자는 다음 두 경로 중 하나로 상대 기록을 공개한다.

- 내 `오늘의 순간`을 남기고 서로의 기록 공개
- 보상형 광고를 끝까지 시청하고 상대 기록만 공개

광고 경로는 그날 기록을 남기기 어려운 사용자의 우회로이며, 광고를 봤다는 사실을 파트너에게 관계 신호로 노출하지 않는다. 현재 앱에는 실제 보상형 광고 SDK가 없으므로 Retention MVP 1에서 새 외부 의존성이 된다.

### 5. 광고 실패는 두 번까지만 재시도한다

보상형 광고가 로드되지 않거나 완료 확인에 실패하면 한 번 더 시도한다. 두 번째 시도도 실패하면 `광고 없이 보기`를 제공한다. 이 무료 우회는 광고 실패 뒤에만 노출하며, 광고·실패·무료 우회 중 어떤 경로로 확인했는지는 파트너에게 보여주지 않는다.

### 6. 자유 기록에 선택형 프롬프트 하나만 보탠다

기존 MomentLoop의 사진·최대 10초 영상·한 문장 자유 입력을 유지한다. 작성 화면에는 `오늘 가장 기억에 남은 순간은?` 프롬프트를 제공하되 사용자가 건너뛸 수 있다. 첫 베타에서는 별도 질문 콘텐츠 시스템이나 Couple 단위 A/B 실험을 만들지 않는다.

### 7. Home 최상단은 상태별 리텐션 카드다

Home 최상단에는 Couple의 오늘 상태에 맞는 주 행동 하나를 보여준다.

- 아무도 기록하지 않음: `오늘의 순간 남기기`
- 상대만 기록함: `내 순간 남기기`와 `광고로 보기`
- 나만 기록함: `내 기록 보기`
- 둘 다 기록함: `오늘의 루프 보기`
- 오늘의 루프 확인 완료: Secret Map·지난 기록 진입

기존 Archive·Secret Map·게임 바로가기는 아래에 유지한다. 게임은 제거하지 않지만 Home의 첫 번째 목적이 되지 않는다.

### 8. 첫 베타에서는 OS 푸시를 제외한다

첫 7일 베타는 Home의 상태별 카드와 앱 실행 중 상태 갱신만 사용한다. 현재 저장소에는 서버의 푸시 토큰 저장 API만 있고 Flutter 토큰 등록과 실제 발송기가 없으므로, OS 푸시는 Retention MVP 1의 첫 구현에 포함하지 않는다.

`오늘의 순간` 자체의 반복 사용 신호가 확인되면 `상대가 오늘의 순간을 남겼어요` 같은 파트너 행동 푸시를 후속 슬라이스로 검토한다.

### 9. 7일 베타의 성공·중단 기준을 먼저 고정한다

계속 개발 조건:

- 참여 Couple의 60% 이상이 7일 중 최소 3일 `오늘의 루프`를 완성한다.
- 루프 완성은 광고 공개가 아니라 두 사람 모두 `오늘의 순간`을 남긴 날만 인정한다.
- 등록된 `오늘의 순간`의 60% 이상을 상대가 24시간 안에 확인한다.
- 베타 종료 후 참여자의 60% 이상이 주 2회 이상 계속 쓰고 싶다고 답한다.

즉시 중단·수정 조건:

- 다른 Couple의 기록 또는 위치·민감한 캡션이 노출된다.
- 파트너 미참여나 광고 실패 때문에 다음 날 진행이 막힌다.
- 2명 이상이 반복적으로 숙제나 재촉처럼 느껴진다고 답한다.

광고 공개율은 성공으로 계산하지 않고 기록 부담을 판단하는 보조 지표로만 사용한다.

### 10. Flutter Web을 먼저 검증한다

Retention MVP 1의 첫 구현과 7일 베타는 Flutter Web에서 진행한다. Web 개발과 성공 기준 검증을 완료한 뒤 Android 테스트로 넘어간다. 첫 스펙과 티켓에는 Android AdMob 연동을 포함하지 않는다.

### 11. 첫 베타의 제품 날짜는 한국 표준시를 사용한다

서버가 `Asia/Seoul` 기준 제품 날짜를 계산하고 저장 타임스탬프는 UTC로 유지한다. 제품 주는 월요일에 시작한다. 향후 Couple 시간대가 도입되면 날짜 계산 정책을 Couple 단위로 확장한다.

### 12. 공개 뒤에는 Today Loop 구성을 고정한다

공개 전에는 Today Moment 지정을 교체하거나 해제할 수 있다. 두 사람의 기여로 Today Loop가 공개된 뒤에는 다른 기록으로 교체하거나 지정을 해제할 수 없다. 작성자의 기존 MomentLoop 삭제 권한은 유지하며 공개된 구성원이 삭제되면 중립적인 삭제 자리로 남긴다.
