## 1. 개요

게임을 시작하기 위해 꼭 필요한 아이템. 기본적으로 **무인도탈출성공 +1%** 효과만 있는 기본 주사위가 주어진다.

- 더 좋은 주사위는 **골드** 또는 **다이아**를 이용해 구입 가능
- 레벨이 높아질수록 되팔기 골드가 남아 주사위를 여러 개 살 수 있음
- **보물쟁탈전 방어**를 감안하면 주사위를 여러 개 사두는 것이 효율적
  - 주사위 4~5개로 미가동 없이 하루 종일 골드벌이 가능

> **메타 변화**: 예전에는 강자의 상징이었지만, 능력치 상향 평준화로 현재는 디자인만 보고 골라도 무방. 단, **스킬 주사위**가 출시되며 행운아이템 슬롯을 아끼기 위해 스킬 주사위는 사실상 필수가 됨.

## 2. 주사위 능력치 전체 설명

### 2-1. 캐릭터 카드와 공유하는 능력치

캐릭터 카드가 보유하는 7가지 능력치를 주사위도 동일하게 공유.
단, **주사위컨트롤** 능력치는 주사위에서 **주사위게이지** 라고 표기됨.

| 능력치 | 설명 | 중요도 |
|--------|------|:------:|
| 🎯 **주사위컨트롤 (주컨/주사위게이지)** | 주사위 게이지 조절 시 원하는 숫자가 나올 확률. 가장 핵심 능력치 | ⭐⭐⭐⭐⭐ |
| 💸 **인수비용할인** | 상대방 땅 인수 시 필요 비용 감소. 파산 위기 탈출 또는 전략적 선점에 유리 | ⭐⭐⭐⭐ |
| 🔨 **건설비용할인 (건할)** | 건물 건설 시 소모 비용 절감. 초반 빠른 랜드마크 선점에 유리 | ⭐⭐⭐⭐ |
| 🎰 **보너스게임승리 (보겜)** | 미니게임(보너스 게임) 승리 확률 증가 | ⭐⭐⭐ |
| 🌟 **황금포츈획득 (포춘/황포)** | 황금 찬스카드 획득 시 유리한 효과 확률 증가 | ⭐⭐⭐ |
| 🏝️ **무인도탈출성공** | 무인도에서 탈출할 확률 증가. 초기 주사위에 주로 탑재 | ⭐⭐ |
| 💰 **특수비용할인** | 세계여행 등 각종 특수 비용 감소. 초기 주사위 일부에 탑재 | ⭐⭐ |

### 2-2. 주사위 고유 능력치

캐릭터 카드에는 없고 **주사위에만 존재하는 4가지 고유 능력치**.

| 능력치 | 설명 | 중요도 |
|--------|------|:------:|
| 💰 **골드 보너스** | 게임 종료 후 획득하는 골드(GP) 추가 % 증가. 강화 자원 수급에 핵심 | ⭐⭐⭐⭐⭐ |
| 🏆 **랭킹점수 보너스 (랭보/RP 보너스)** | 획득 랭킹 포인트(RP) 추가 증가. 천공의 주사위 이후 미출시 (SVIP 전용 제외) | ⭐⭐⭐ |
| ➕➖ **홀짝 보너스** | 홀짝 아이템 구매 시 사용 횟수 추가. 주컨 전략과 연계하여 핵심 역할 | ⭐⭐⭐⭐ |
| 📈 **경험치 보너스** | 게임 결과 경험치 획득량 증가. 초기 주사위에 주로 탑재 | ⭐⭐ |

### 2-3. 능력치 유형 조합 패턴

LED 주사위 출시 이후 능력치 구성 획일화. 나비 주사위 이후부터 아래 두 가지 패턴만 출시됨.

#### 패턴 A: 포춘 + 건할 + 주컨 + 인할

| 골드 보너스 | 랭킹점수 보너스 |
|------------|--------------|
| LED, 1등, 임페리얼, 나비, 치유, 화염, 눈꽃, 개구리왕자, 동키팝, 뛰뛰빵빵, 카니발, 할로윈, 스노우볼, 3주년, 꼬꼬맘, 셜록, 한여름밤, 산호, 우주선, 겨울썰매 | 모닝스타, 천공, 배드바츠마루 |

#### 패턴 B: 보겜 + 건할 + 주컨 + 인할

| 골드 보너스 | 랭킹점수 보너스 |
|------------|--------------|
| 아토믹, 시한폭탄, 토이블럭, 헬로키티, 봄꽃, 몽키, 스타레인, 그리핑크스, 항해사, 보름달, 허수아비, 재즈, 복주머니, 피크닉, 회전목마, 4주년, 여행가방, 요술냥이, 봅슬레이 | 트럼프 |

#### 패턴 C: 기타 특수 조합

| 패턴 | 해당 주사위 | 특이사항 |
|------|-----------|---------|
| 보겜 + 포춘 + 주컨 + 인할 | 고대인(VIP), 진주, 보석(VIP), 메탈기어 | 건설비용할인 없음 |
| 보겜 + 포춘 + 주컨 + 골드 + 랭점 | 스컬, 정복자, 매트릭스 | 건할·인할 없음, 랭커 선호 |
| 보겜 + 포춘 + 건할 + 주컨 + 인할 | 큐브, 파라오, 플라워 | 5종 풀 조합 |

## 3. 강화 시스템

### 기본 구조



- **강화 실패 없음** — 확정 레벨업 (캐릭터 카드/행운아이템과 다름)
- **골드만 소모** — 별도 재료 불필요 (일부 특수 주사위 제외)
- **강화하지 않으면 능력치 거의 미발동** — 반드시 만렙(Lv.10) 목표

### 레벨별 효과

| 레벨 | 특이사항 |
|------|---------|
| Lv. 1 | 기본 능력치 (매우 낮음) |
| Lv. 2 ~ 4 | 능력치 점진적 상승 |
| **Lv. 5** | ✨ 주사위 던질 때 **특수 이펙트 1단계** 추가 |
| Lv. 6 ~ 9 | 능력치 계속 상승 |
| **Lv. 10 (MAX)** | 🎆 **특수 이펙트 2단계** + **능력치 최대치** 발휘 |

### 합성 시스템

> ⚠️ 주사위는 캐릭터 카드처럼 합성으로 등급을 올리는 방식이 **존재하지 않음**

- **되팔기**: 더 좋은 주사위 구매 후 기존 주사위 골드로 판매 가능
- **주사위 조각**: 특정 이벤트로 조각을 모아 특정 주사위 제작 가능 (이벤트마다 상이)
- **스킬 주사위**: 주컨 정확도 기능 내장 → 행운아이템 슬롯 절약

| 랭킹 상위 도전 | 천공, 배드바츠마루, 모닝스타 | 랭킹점수 보너스 포함 |
| 보물쟁탈전 방어 | 최신 주사위 여러 개 보유 | 최신일수록 방어 시간 김 |

### 핵심 요약

- **강화는 필수**: 강화 없으면 능력치 거의 발동 안 됨
- **골드 보너스 중요**: 주사위가 유일하게 제공하는 골드 보너스 장비
- **보물쟁탈전 여러 개 유지**: 4~5개로 하루 종일 방어 가능
- **스킬 주사위 필수화**: 행운아이템 슬롯 절약 위한 스킬 내장 주사위 트렌드
- **메타 주기적 확인**: 공식 카페·커뮤니티 최신 공략 확인 권장
