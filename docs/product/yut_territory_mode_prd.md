## 1. 개요

### 1.1 한 줄 소개

전통 윷판 위에서 영지를 사고 빼앗으며 싸우는 **2인 실시간 전략 보드게임**.

### 1.2 기획 목적

모두의 마블의 저작권·특허 리스크(사각 맵, 랜드마크, 주사위 더블)를 100% 제거하고, 퍼블릭 도메인인 **전통 29칸 윷판**과 윷놀이 고유의 **잡기·업기** 메카닉을 결합한 독자적 전략 영토 난투 보드게임.

### 1.3 게임 정보

| 항목 | 내용 |
|------|------|
| 장르 | 윷놀이 기반 전략 영토 점령 보드게임 |
| 인원 | 2인 (1v1) |
| 플레이 시간 | 한 판당 5~10분 (최대 20턴 제한) |
| 핵심 재미 | 윷/모의 속도감, 말 잡기·업기의 역전 쾌감, 130% 인수전, 라인·신수 독점 전략 |

## 2. 맵 구조

### 2.1 전통 29칸 윷판

```
        [주작 10] ====== 11·12·13·14 ====== [백호 15]
            ║  ╲                              ╱  ║
            ║     24·25                  26·27   ║
          9·8·7·6   ╲  [중앙 23]   ╱   16·17·18·19
            ║       21·22     28·29       ║
            ║  ╱                              ╲  ║
        [청룡  5] ====== 4·3·2·1  ====== [현무  0 (출발)]
```

### 2.2 칸 분류

| 분류 | 위치 | 설명 |
|------|------|------|
| **신수 모서리** | 0·5·10·15 (4칸) | 4대 신수 거점, 최대 2단계 |
| **대각선 지름길** | 21~29 (9칸) | X자 지름길, 최대 3단계 |
| **일반 외곽** | 1~4·6~9·11~14·16~19 (16칸) | 표준 영지, 최대 3단계 |

> 총 29칸 모두 영지로 기능하며 구매·업그레이드·통행료·인수 대상.

### 2.3 라인(변) 정의

각 변은 **시작 신수 1칸 + 내부 4칸 = 5칸**으로 구성. 끝 모서리는 다음 변 소속.

| 변 이름 | 구성 칸 |
|---------|---------|
| 현무변 | 0 · 1 · 2 · 3 · 4 |
| 청룡변 | 5 · 6 · 7 · 8 · 9 |
| 주작변 | 10 · 11 · 12 · 13 · 14 |
| 백호변 | 15 · 16 · 17 · 18 · 19 |

> 대각선 칸(21~29)은 어느 변에도 속하지 않으므로 라인 독점 카운팅에서 제외.  
> 각 모서리는 정확히 한 변에만 귀속 — 중복 없음.

## 3. 경제 시스템

### 3.1 기준값

| 항목 | 금액 |
|------|------|
| 시작 자금 | **5,000만원** |
| 완주 월급 | **500만원** (선 통과마다) |
| 인수 방식 | 구매가 × 1.3을 상대방에게 지불 |
| 인수 후 단계 | 1단계로 리셋 |

### 3.2 칸별 수치표

| 칸 종류 | 구매가 | 1단 통행료 | 2단 통행료 | 3단 통행료 | 1→2 업 | 2→3 업 | 인수가 |
|---------|--------|-----------|-----------|-----------|--------|--------|--------|
| 일반 (16칸) | 200만 | 100만 | 250만 | 500만 | 200만 | 400만 | 260만 |
| 대각선 (9칸) | 300만 | 150만 | 375만 | 750만 | 300만 | 600만 | 390만 |
| 신수 (4칸) | 500만 | 250만 | 600만 | — | 400만 | — | 650만 |

**업기 50% 할인 적용 시 인수가**: 일반 130만 / 대각선 195만 / 신수 325만

### 3.3 영지 단계 시스템

영지는 최대 3단계(신수는 2단계)로 강화 가능.

| 단계 | 명칭 | 효과 | 인수 가능 |
|------|------|------|----------|
| **1단계** | 점령 | 기본 통행료 | ✅ |
| **2단계** | 강화 | 통행료 2.5배 | ✅ |
| **3단계** | 수호 | 통행료 5배 + **인수 불가 보호막** | ❌ |

> 신수 4칸은 최대 2단계. 신수 독점 승리를 위해 항상 인수 가능해야 하므로 보호막 없음.

**업그레이드 방식**: 내 말이 내 영지에 도착하는 순간 "강화하기 / 유지" 팝업 표시. 자금 부족 시 팝업 없이 통과. 별도 행동 없음.

### 3.4 서든데스 자산 계산 (20턴 종료 시)

```
자산 = 현금 + Σ(영지별 구매가 + 투자한 업그레이드 비용 누계)
```

| 예시 | 자산 가치 |
|------|----------|
| 일반 1단계 | 200만 |
| 일반 2단계 | 200 + 200 = 400만 |
| 일반 3단계 | 200 + 200 + 400 = 800만 |
| 신수 1단계 | 500만 |
| 신수 2단계 | 500 + 400 = 900만 |

## 4. 말 시스템

### 4.1 기본 구조

- 플레이어당 **말 2개** 보유.
- **완주(선 통과) = 게임 종료 조건이 아님.** 월급 500만원 수령 후 즉시 0번(출발점)에서 재출발.
- 말은 항상 판 위에 2개 유지. 제거되지 않음.

### 4.2 단독 이동 vs 업기

```
[단독 이동]                 [업기 — 2단 합체]
 ─────────────────          ──────────────────────────────
 안전: 잡혀도 말 1개만        위험: 잡히면 말 2개 동시 출발점 복귀
 기본 영지 점령 및 통행료      이익 1: 빈 영지 도착 시 점령비 2배 내고 2단계 직행
                            이익 2: 인수 시 비용 50% 할인
```

**업기 조건**: 내 말 2개가 같은 칸에 도착하면 자동 합체.

## 5. 턴 구조

### 5.1 턴 정의

> **1턴 = 연속 던지기(윷·모 포함) 전체가 끝날 때까지 한 플레이어의 1사이클**

- 윷·모로 연속 던지기가 발생해도 같은 턴 안에 포함, 턴 수 증가 없음.
- 총 20턴 = 각 플레이어 10번씩.

### 5.2 일반 턴 흐름

```
1. 윷 던지기
2. 이동할 말 선택
3. 말 이동
4. [착지 처리]
   ─ 빈 칸:       "점령하기 / 패스" 선택
   ─ 내 영지:     "강화하기 / 유지" 선택
   ─ 상대 영지:   통행료 자동 지불
                  자금 부족 → 파산 판정
5. 남은 pendingMoves가 있으면 2번으로
6. 윷·모 보너스 던지기 남아 있으면 1번으로
7. 턴 종료 → 상대 턴
```

### 5.3 잡기 발생 시 턴 흐름

```
1. 내 말이 상대 말과 같은 칸 도착 → 잡기 성공
2. 상대 말 출발점(0번) 복귀
3. [인수 기회] "인수하기 / 패스" 선택
   ─ 인수하기: 구매가 × 1.3을 상대에게 지불, 해당 영지 1단계로 취득
               업기 상태라면 할인 미적용 (잡기 인수는 별도 이벤트)
   ─ 패스:     인수 없이 진행
4. 보너스 던지기 1회 획득 → 1번(일반 턴 흐름 1번)으로
```

> 인수 기회는 보너스 던지기 **전에** 처리. 자금 부족 시 인수 불가(패스 처리).

## 6. 윷 던지기

### 6.1 기본 결과

| 결과 | 이동 | 보너스 던지기 |
|------|------|-------------|
| 도 | 1칸 | ❌ |
| 개 | 2칸 | ❌ |
| 걸 | 3칸 | ❌ |
| 윷 | 4칸 | ✅ |
| 모 | 5칸 | ✅ |
| 빽도 | -1칸 | ❌ |

### 6.2 빽도 메카닉

윷가락 4개 중 1개에 X표시 존재. X표시 1개만 뒤집히고 나머지 3개가 엎어진 경우 빽도(-1칸) 발동.

**전략적 활용**:
- 지나쳐버린 내 영지로 되돌아가 강화.
- 지름길 진입로 직전 칸으로 후퇴 후 다음 턴 지름길 진입.

**빽도 특수 케이스**:
- 0번(출발점)에서 빽도 → 이동 없음.
- 분기점(23번)에서 빽도 → 직전 경로 방향으로 후퇴 (22번 또는 25번).
- 업기 상태에서 빽도 → 합체 상태 유지 그대로 -1칸 이동.

## 7. 승리 조건

게임은 아래 4가지 조건 중 하나라도 충족되는 즉시 종료.

### 7.1 4대 신수 독점 승리

4개 신수 모서리 칸(0·5·10·15)을 **동시에** 모두 점령하면 즉시 승리.

> 신수는 최대 2단계이며 항상 인수 가능. 끊임없이 뺏고 빼앗기는 난투 유도.

### 7.2 한 변(Line) 독점 승리

현무·청룡·주작·백호 4개 변 중 어느 한 변의 **5칸을 연속으로 모두 점령**하면 즉시 승리.

> 대각선 칸은 라인 카운팅 제외. 모서리 칸은 해당 변의 시작 칸으로 귀속.

### 7.3 파산 승리

상대 자금이 0원 이하가 되면 즉시 승리.

> 통행료·인수 비용 지불 후 잔액이 음수가 되는 시점에 파산 판정.

### 7.4 20턴 서든데스 승리

20턴(각 플레이어 10번) 종료 시 아무도 위 3가지 조건을 달성하지 못했을 때:

```
자산 = 현금 + Σ(구매가 + 업그레이드 누계)
```

자산이 높은 플레이어 승리. 동점 시 영지 수가 많은 쪽 승리.

## 9. 구현 메모

### 현재 yut-engine.js와의 차이점

| 항목 | 기존 윷놀이 | 영토 윷놀이 |
|------|-----------|-----------|
| 말 수 | 4개 | 2개 |
| 승리 조건 | 모든 말 완주 | 신수 독점 / 라인 독점 / 파산 / 서든데스 |
| 완주 처리 | 게임에서 제거 | 월급 수령 후 재출발 |
| 경제 시스템 | 없음 | 영지·통행료·인수 |
| 업기 효과 | 이동만 | 2단계 직행 + 50% 인수 할인 |

### 서버 추가 상태 (게임 state)

```js
{
  // 기존 유지
  playersOrder, players.pieces, phase, currentTurn, pendingMoves,
  hasBonusThrow, caughtOpponentThisTurn, winner, lastThrow,

  // 신규 추가
  territories: {
    [position]: { owner: userId | null, level: 1 | 2 | 3 }
  },
  wallets: {
    [userId]: number   // 보유 자금 (원 단위)
  },
  turnCount: number,   // 0부터 시작, 20에서 서든데스
  pendingInsuOpportunity: {   // 잡기 후 인수 기회 대기 상태
    position: number | null,
    stacked: boolean          // 업기 여부 (할인 적용 무관)
  }
}
```

### 소켓 이벤트 (신규)

| 이벤트 | 방향 | 설명 |
|--------|------|------|
| `game:yut2:new` | server→client | 게임 시작, 초기 상태 전송 |
| `game:yut2:state` | server→client | 상태 전체 동기화 |
| `game:yut2:claim` | client→server | 영지 점령/패스 선택 |
| `game:yut2:upgrade` | client→server | 영지 강화/유지 선택 |
| `game:yut2:insu` | client→server | 잡기 후 인수 기회 응답 |

> 기존 `game:yut:*` 이벤트와 별도 네임스페이스로 분리. 두 모드 동시 운용 가능.
