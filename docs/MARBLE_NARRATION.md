# 마블 게임 나레이션 대사

## 턴 / 순서

| 상황 | 대사 |
|------|------|
| 선 정하기 시작 | "주사위 굴려서 순서 정해봐요" / "누가 먼저 갈지 정하는 시간이에요" |
| 내가 선 | "제가 먼저 하겠습니다~" / "선 갔어요! 고고" |
| 상대가 선 | "저는 두 번째네요" / "나중에 가는 게 더 좋은 거라고요 (아님)" |
