# Spec: Secret Base 보안·안전·운영 하드닝 (2026-11)

게임을 제외한 전체 코드 리뷰(서버·Flutter 앱·운영)에서 나온 결함을 정리한 스펙이다. 용어는 `CONTEXT.md`의 정의를 따른다(계정, 활성 커플, MomentLoop, 연결 해제 등).

## Problem Statement

사용자는 두 사람만의 사적인 기록과 마음 이야기를 맡기고 있는데, 현재 운영 서버에는 다음 문제가 있다.

- 결제를 하지 않아도 프리미엄이 켜질 수 있다. 기능 게이트가 경로 대소문자를 구분해서 막아둔 기능이 우회될 수 있다.
- 상담 채팅에서 위기 신호("죽고 싶다" 등)를 감지하지 않아 안전 안내가 나오지 않는다. 마음관리의 위기 키워드도 빈약하다.
- 파트너가 API로 직접 호출하면 상대의 MomentLoop 기록을 삭제할 수 있다.
- 업로드 파일 확장자를 클라이언트 값으로 정해 공개 서빙하므로 악성 파일이 같은 오리진에서 실행될 수 있다.
- 로그인·가입에 시도 횟수 제한이 없고 기본 보안 헤더가 없다.
- 탈퇴한 계정의 토큰이 만료 전까지 계속 유효하다.
- 서버 테스트가 운영 `.env`를 읽어 운영 서버에서 실패하고, 배포 스크립트는 마이그레이션·웹 교체 순서와 롤백이 위험하다.
- 앱은 느린 망에서 무한 대기하고, 토큰이 만료되면 사용자가 로그인 상태로 착각한 채 빈 화면을 본다.

## Solution

사용자 관점에서 다음이 보장되도록 한다.

- 결제 검증 없이는 프리미엄이 되지 않고, 비활성화된 기능은 어떤 대소문자·형태로 호출해도 닫혀 있다.
- 상담 중 위기 신호가 보이면 AI 답변 대신 즉시 안전 안내(도움 기관 연락처)가 나온다.
- 기록 삭제는 작성자만 할 수 있고, 파트너의 수정 허용은 유지된다.
- 업로드는 허용된 이미지·영상 형식만 저장되고, 서빙 시 브라우저가 실행하지 못한다.
- 로그인 무차별 대입이 제한되고 기본 보안 헤더가 붙는다.
- 탈퇴한 계정의 토큰은 즉시 거부된다.
- 배포는 마이그레이션을 먼저 하고 직전 웹 빌드를 보관하며, 서버 테스트가 운영 환경에 오염되지 않는다.
- 앱은 시간 초과를 명확히 처리하고, 세션이 만료되면 로그인 화면으로 돌려보낸다.

## User Stories

1. 사용자로서, 결제하지 않으면 프리미엄이 켜지지 않기를 원한다, 그래야 결제한 사용자와 공정하다.
2. 운영자로서, 비활성화된 기능 경로가 대소문자를 바꿔도 막히기를 원한다, 그래야 MVP 범위 밖 기능이 노출되지 않는다.
3. 운영자로서, 데모용 결제 활성화가 운영에서 동작하지 않기를 원한다, 그래야 매출 누수가 없다.
4. 상담을 쓰는 사용자로서, 힘든 마음을 적었을 때 즉시 도움 기관 안내를 받기를 원한다, 그래야 위기에서 도움을 찾을 수 있다.
5. 상담을 쓰는 사용자로서, 띄어쓰기 없이 써도("죽고싶어") 위기 신호가 감지되기를 원한다.
6. 운영자로서, "자살", "극단적 선택", "뛰어내리" 같은 흔한 표현이 감지되기를 원한다.
7. 상담을 쓰는 사용자로서, 위기 안내가 나올 때 외부 AI로 내 메시지가 전송되지 않기를 원한다, 그래야 민감한 대화가 새지 않는다.
8. 활성 커플의 사용자로서, 파트너가 내 MomentLoop 기록을 삭제하지 못하기를 원한다, 그래야 내 기록이 안전하다.
9. 활성 커플의 사용자로서, 파트너가 내 기록을 함께 수정할 수 있기를 원한다(현재 정책 유지).
10. 사용자로서, 올린 사진·영상이 다른 사람의 코드 실행에 쓰이지 않기를 원한다.
11. 운영자로서, 이미지·영상이 아닌 파일 업로드가 거부되기를 원한다.
12. 운영자로서, 서빙되는 업로드 파일에 `nosniff`와 샌드박스 헤더가 붙기를 원한다.
13. 사용자로서, 내 계정에 무차별 로그인 시도가 계속되지 않기를 원한다.
14. 운영자로서, 로그인·가입·구글 인증에 시도 횟수 제한이 있기를 원한다.
15. 운영자로서, 모든 응답에 기본 보안 헤더가 붙기를 원한다.
16. 사용자로서, 구글로 가입한 계정에 비밀번호 로그인을 시도해도 서버 오류가 아니라 일반 인증 실패를 받기를 원한다.
17. 탈퇴한 사용자로서, 탈퇴 직후 내 토큰으로 더 이상 접근되지 않기를 원한다.
18. 운영자로서, 데이터베이스 오류 로그에 이메일·해시·푸시 토큰이 남지 않기를 원한다.
19. 사용자로서, 푸시 payload 문제 하나로 내 기기 토큰이 지워지지 않기를 원한다.
20. 사용자로서, 연결 해제된 옛 커플의 파트너에게 쿠폰이 발급되지 않기를 원한다.
21. 사용자로서, 이미 사용·취소된 소원권이 다시 사용되지 않기를 원한다.
22. 운영자로서, 서버에서 테스트를 돌려도 운영 `.env`가 테스트 환경을 덮어쓰지 않기를 원한다.
23. 운영자로서, 마이그레이션이 실패하면 웹 빌드가 이미 교체되어 있지 않기를 원한다.
24. 운영자로서, 배포 직전 웹 빌드가 보관되어 수동 롤백이 가능하기를 원한다.
25. 운영자로서, 헬스체크가 기동 지연을 충분히 기다리기를 원한다.
26. 운영자로서, 동시에 두 배포가 돌지 않기를 원한다.
27. 앱 사용자로서, 느린 망에서 요청이 무한히 기다리지 않기를 원한다.
28. 앱 사용자로서, 세션이 만료되면 빈 화면 대신 로그인 화면으로 이동하기를 원한다.
29. 앱 사용자로서, 기기 백업에 내 로그인 토큰이 복사되지 않기를 원한다.
30. 웹 사용자로서, GitHub Pages 주소에서도 구글 로그인이 되기를 원한다.

## Implementation Decisions

- 기능 게이트는 경로를 소문자로 정규화해 비교한다. 라우터 자체의 대소문자 민감도는 바꾸지 않는다(기존 클라이언트 호환).
- 프리미엄 활성화는 결제 검증 수단이 없으므로 기본적으로 거부한다. 개발 환경에서만 명시적 설정으로 데모 활성화를 허용한다. 영수증/웹훅 검증은 별도 결정이 필요하다(지도의 Not yet specified).
- 상담(개인·공유)의 메시지 처리 경로에서 저장·LLM 호출 전에 위기 감지를 수행한다. 감지되면 LLM을 호출하지 않고 안전 리소스와 고정 문구를 반환한다. 위기 감지는 마음관리와 같은 단일 모듈을 쓴다. 키워드는 공백 무시 매칭으로 보강한다. 부정문 오탐은 안전한 방향이므로 허용한다.
- MomentLoop 삭제는 서버에서 작성자만 허용한다(`moment_author_required`). 수정은 기존대로 활성 커플의 파트너에게 허용하고 문서를 현재 정책에 맞춘다.
- 업로드는 확장자를 허용 MIME 화이트리스트에서 유도하고 그 외는 거부한다. 서빙 응답에는 `nosniff`와 스크립트 실행을 막는 CSP 샌드박스를 붙인다. 인증 서빙(서명 URL)은 클라이언트 변경이 필요하므로 이번 범위 밖이다.
- 로그인·가입·구글 인증에는 외부 의존성 없는 자체 제한기를 둔다(IP 기준 + 가능하면 이메일 기준 슬라이딩 윈도우). 응답 코드는 429와 `Retry-After`. 기본 보안 헤더는 직접 설정한다.
- 인증 미들웨어는 토큰 검증 후 계정 활성 여부를 짧은 TTL 캐시로 확인하고, 탈퇴 시 캐시를 무효화한다. 확인 중 DB 오류는 요청을 막지 않고(fail-open) 로그만 남긴다.
- 테스트 환경(`NODE_ENV=test`)에서는 `.env` 자동 로딩을 건너뛴다. 운영 동작은 바꾸지 않는다.
- 소소한 결함(비밀번호 해시 없는 계정 로그인, DB 로그의 파라미터 노출, 푸시 토큰 폐기 조건, 쿠폰 발급 대상의 활성 커플 조건, 소원권 상태 전이)은 각각 최소 수정한다.
- 앱의 `ApiClient`에 기본 타임아웃과 401 콜백을 추가하고 인증 서비스가 로그아웃에 연결한다. 안드로이드 자동 백업을 끈다.
- 배포는 마이그레이션 → 웹 교체 → 재시작 순서로 바꾸고 직전 웹 빌드를 보관한다. 배포 워크플로에 동시성 제한을 둔다. Pages 빌드에 구글 클라이언트 ID를 전달한다.

## Testing Decisions

- 좋은 테스트는 외부 동작(HTTP 응답, 반환 값)만 검증한다. 구현 세부사항에 묶지 않는다.
- 서버: 기능 게이트의 대소문자 변형, 위기 감지(띄어쓰기·키워드), MomentLoop 삭제 권한, 업로드 필터, 제한기, 계정 활성 확인을 단위/모듈 테스트로 검증한다. 기존 선례는 `services/realtime-server/test`의 노드 테스트(`node --test`)와 MomentLoop 모듈 테스트다.
- 앱: `ApiClient`의 타임아웃과 401 콜백을 기존 `api_client_test` 방식(가짜 `http.Client`)으로 검증한다.
- 테스트 실행은 운영 환경과 분리된 임시 사본에서 한다. 로컬에는 node/flutter가 없다.

## Out of Scope

- 모든 게임 코드와 게임 문서.
- 토큰 보안 저장소 도입, l10n, 대형 파일 분리, 레거시 라우트 제거/재스코핑, 인증 업로드 서빙, 외부 LLM 개인정보 정제, 백업 스크립트 개편, UGC 신고·차단, CI 게이트와 통합 테스트 연동, 모니터링. 이들은 결정이 더 필요해서 지도의 Not yet specified에 남긴다.
