# 02. 구현 계획 — 홈·기록 탭 재설계 + 상점 조회 수정

> 2026-11-11. `01-grilling.md`의 확정안을 앱에 옮기는 순서예요.
> 기준 목업: 홈은 `home-final.html`의 ①, 기록 탭은 `record-prototype.html`(v2).

## 이미 있는 것 (새로 만들 필요 없음)

서버 `modules/moment-loop`에 SNS 기능의 바탕이 이미 있어요. 화면만 새로 만들면 돼요.

| 기능 | 서버 |
|---|---|
| 사진 목록·올리기 | `GET/POST /setlog` |
| 한 줄 글 | 게시물 `caption` 필드(올릴 때·`PATCH /setlog/:id`) |
| 하트(반응) | `POST /setlog/reaction`. 사람마다 이모지 하나, 다시 누르면 취소 |
| 댓글 | `GET/POST/DELETE /setlog/:postId/comments` |
| 오늘의 순간(둘 다 남기면 열림) | `GET /retention/today`, `PUT/DELETE /retention/today/moment` |

없는 것은 **썸네일**이에요. 처음에는 앱에서 작게 줄여 디코딩해요(`cacheWidth`). 서버 썸네일 생성은 나중 단계예요.

## 단계

### 1. 디자인 토큰 v3 (먼저)

- 바탕·글자·간격·모서리를 목업 기준으로 다시 정해요.
  - 흰 바탕, 큰 글자, 장식 없음, 카드 모서리 24, 그림자 거의 없음
- 테마 7종(PR #270)은 그대로 두고, **강조색과 바탕 톤만** 바뀌게 맞춰요.
  - 기록 탭은 테마와 상관없이 어두운 화면이에요. 강조색만 따라가요.
- 글꼴은 Pretendard Variable 한 파일(약 2MB)을 앱에 넣는 것을 추천해요. 지금 쓰는 Noto Sans KR보다 목업 느낌에 가까워요.
  - Pretendard는 OFL 라이선스예요.
  - **사용자 확인이 필요해요.** 폰트 파일을 내려받아 넣어야 해요.

### 2. 홈

- 상단: 날짜 / 함께한 지 N일 / 다음 기념일 칩, 오른쪽 아바타 쌍
- 중단: "지금 할 일" 카드 한 장. 우선순위는 오늘의 순간 → 운세 → 끝(둘의 사진)
- 하단: 조용한 한 줄. 상태에 따라 운세 또는 오늘의 순간, 그리고 항상 지난 순간
- 기존 4칸 메뉴(우리 이해·비밀기지 등)는 홈에서 빼고 더보기로 옮겨요.
- 텐트 일러스트는 홈에서 빠져요.

### 3. 기록 탭

- 한 장씩: 세로 페이지 피드, 위쪽 스토리 줄, 작은 사진 눌러 바꾸기, 두 번 탭 하트, 댓글 시트(이모지 빠른 반응)
- 잠긴 오늘: 아래쪽 "내 순간 올리기" 큰 버튼 → 카메라/앨범 → 한 줄(선택) → 올리기
- 모아보기: 달력 격자. 날짜를 누르면 그날 피드로 가요.
- 지금의 오늘 / 이번 주 / 지난 기록 구분과 보기 방식 버튼은 위 두 화면으로 대체해요.
- 기존 상세·작성 화면(`moment_detail.dart`, `moment_composer.dart`)의 업로드·편집 로직은 재사용해요.

### 4. 상점 조회 수정 + 새 스타일

- 원인 후보: `shop_screen.dart`가 API 7개를 `Future.wait`로 한꺼번에 받아요. **하나만 실패해도 전체가 "조회 실패"가 돼요.**
  - 해당 API: items, wallet, coupons, owned, equipped, user/level, missions
- 수정:
  - 섹션별로 따로 받아서, 실패한 섹션만 다시 시도하게 해요.
  - 어떤 API가 실패하는지 로그로 남겨요.
  - 운영 서버 로그로 실제 실패 API를 확인해요. 사용자 허락이 있을 때만 봐요.
- 화면은 토큰 v3 스타일로 다시 입혀요.

### 5. 나머지 탭

지도·놀이·더보기는 토큰 v3만 적용해요(레이아웃은 유지). 게임 화면은 그대로예요.

## 검증

- 각 단계마다 `flutter analyze`, `dart format`, `flutter test`를 돌려요.
- 가짜 API(포트 4200)로 웹에서 화면을 확인해요.
- 마지막에 태블릿에 debug 빌드를 설치해요.
- 배포는 사용자가 말할 때만 해요.
