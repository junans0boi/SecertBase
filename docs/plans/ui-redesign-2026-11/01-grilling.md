# 01. Grilling — 앱 UI/UX 재정의 (홈 화면부터)

> 2026-11-11. 사용자와 직접 진행한 그릴링이에요. ❓는 질문, 💬는 사용자 답, ➡️는 결정이에요.
> 출발점: 2.0 디자인(PR #269)과 색 테마 7종(PR #270)을 배포한 뒤에도 사용자는 "앱 전체 UI/UX/레이아웃이 너무 촌스럽다"고 판단했어요. 상점은 "조회가 안 된다"고 보고했어요.

---

## Round 1 — 무엇이 문제인가

❓ **Q1 - 홈에서 촌스럽다고 느끼는 부분은?** (일러스트·장식 / 카드·버튼 모양 / 글꼴·숫자 / 정보 배치·밀도)

💬 "아이콘은 어쩔 수 없다 쳐도 레이아웃? 배치? 이미지 등? 너무 촌스러워."

➡️ 결정:
- 바꿀 대상은 **레이아웃·배치·이미지 표현**이에요.
- 아이콘 세트는 이번 범위에서 우선순위가 낮아요. 바꿔도 되지만 필수는 아니에요.

❓ **Q2 - 새 방향은 어떤 앱 느낌? (클린 미니멀 / 사진 중심 / 감성 다이어리 / 귀엽고 게임스러운)**

💬 "4개 중에 고르진 못할 것 같고 예시 디자인이 있어야 선택하기 좋을 듯."

➡️ 결정: 말로 고르지 않아요. **홈 화면 HTML 목업 여러 개**를 보고 고르기로 해요.

❓ **Q3 - 홈의 주인공은?**

💬 홈에 필요한 정보:
- 오늘이 며칠인지
- 다음 기념일까지 남은 날
- 오늘의 운세. 아직 안 봤다면 페이지 이동을 유도해요.
- 오늘의 순간. 업로드 안 했다면 업로드를 유도하고, 최근 이미지를 보여 줘요.

우선순위는 리드 추천을 따르되, **사용자가 앱 이용에 피로를 느끼지 않게** 해 달라고 했어요.

➡️ 결정 (리드 추천):
- **한 번에 하나만 크게 조르기.** 아직 안 한 일 중 가장 중요한 것 하나만 강조해요.
  - 우선순위는 오늘의 순간 > 운세예요.
  - 나머지 정보는 조용한 한 줄로 둬요.
- 날짜와 D+는 항상 보이지만 작게 둬요. 기념일은 칩 하나로 보여 줘요.
- 빨간 배지, 여러 개의 CTA, 반복 팝업으로 재촉하지 않아요. 안 본 운세는 작은 점 하나로만 알려요.

❓ **Q4 - 상점은 어떻게 안 되나?**

💬 "조회 안 됨." 목록이 안 떠요.

➡️ 결정: 새 UI를 적용할 때 상점 화면을 다시 만들면서 **조회 실패 원인도 함께 고쳐요**. 원인 조사는 구현 단계에서 해요.

---

## Round 2 — 목업 방식

❓ **Q5 - 홈 구성(날짜 한 줄 + 기념일 칩 / 오늘의 순간 주인공 / 운세 한 줄 / 4칸 메뉴 제거)을 모든 목업에 공통으로 쓸까?**

💬 "목업마다 다르게."

➡️ 결정:
- 목업마다 **구성 자체를 다르게** 해서 비교해요.
- 모든 목업에 들어가는 정보는 Q3의 네 가지(날짜·D+, 다음 기념일, 운세, 오늘의 순간)로 같아요.

❓ **Q6 - 텐트·달 일러스트는?**

💬 "현재 목업은 촌스러워."

➡️ 결정:
- 지금의 일러스트 스타일(텐트·달·언덕·하트·반짝이)은 **쓰지 않아요**.
- 이미지 표현(사진 중심, 타이포 중심, 추상 그래픽 등)은 목업마다 다르게 보여 줘요.

❓ **Q7 - 목업 개수와 형식?**

💬 "4~5개 알아서."

➡️ 결정:
- 방향이 확실히 다른 **홈 화면 5개**를 한 페이지에 나란히 놓아요.
- 모두 같은 데이터를 써요(민지·서윤, 함께한 지 412일, 서윤 생일 D-26).
- 상태 토글 두 개를 둬서 모든 목업에 한 번에 적용해요.
  - 오늘의 순간: 업로드 전 / 둘 다 올림
  - 운세: 안 봄 / 봄

## Round 3 — 1차 목업 결과 (`home-directions.html`)

❓ **Q8 - 5개(A 클린 리스트 / B 매거진 / C 사진 풀스크린 / D 위젯 타일 / E 하나씩 카드) 중 어느 쪽?**

💬 "A / C / (D+E)가 좋은데."

➡️ 결정:
- B(매거진)는 제외해요.
- 2차 목업(`home-directions-r2.html`)은 세 후보를 더 다듬어요.
  - **A**: 클린 리스트
  - **C**: 사진 풀스크린
  - **D+E**: 위젯 타일 위에 "지금 할 일" 카드 한 장을 얹은 하이브리드. 할 일이 끝나면 그 자리에 둘의 사진이 들어가요.
- 2차 목업에는 강조색 토글(코랄·블루·그린·라벤더)을 넣어서, 테마 색이 바뀌어도 방향이 유지되는지 같이 봐요.

---

## Round 4 — 2차 목업 결과 (`home-directions-r2.html`)

❓ **Q9 - 세 방향(A 클린 리스트 / B 사진 풀스크린 / C 위젯 타일 + 지금 할 일) 중 최종은?**

💬 홈은 조합으로 일단 결정:
- [상단] A의 머리 부분: "11월 11일 수요일 / 함께한 지 412일 / ● 서윤 생일까지 26일". 오른쪽에 프로필 아이콘(두 사람 겹친 아바타).
- [중단] C의 "지금 할 일" 카드(예: "서윤이 오늘의 순간을 남기고 기다려요").
- B(사진 풀스크린)는 **기록 탭**에 쓰고 싶다. 효율적이고 부담스럽지 않은 방법은?

➡️ 결정:
- 홈 상단은 A 머리 + 오른쪽 아바타 쌍, 중단은 C의 지금 할 일 카드로 확정해요.
- 홈 하단은 리드 추천으로 정해요(사용자 확인 대기).
  - 412일·D-26은 상단에 이미 있으니 C의 숫자 타일은 빼요.
  - A식 조용한 한 줄 목록(오늘의 운세, 지난 순간)만 둬요.
- 기록 탭은 B 방식으로 가요(리드 추천, 사용자 확인 대기).
  - **기본 화면은 하루 한 장 세로 피드예요.** 위아래로 넘기면 날짜가 바뀌고, 좌우로 넘기면 내 사진과 상대 사진이 바뀌어요.
  - **모아보기(달력 격자)는 보조 화면이에요.** 오래된 날을 찾을 때만 써요.
  - 부담 줄이기:
    - 사진이 없는 날은 피드에서 건너뛰고, 작은 간격 표시만 해요.
    - 글·댓글은 필수가 아니에요. 반응은 하트 하나뿐이에요.
    - 자동 재생, 연속 알림은 없어요.
  - 효율:
    - 썸네일을 먼저 받고, 앞뒤 이틀만 미리 받아요. 원본은 볼 때 받아요.
    - 오늘을 아직 안 올렸으면 피드 첫 장이 홈과 같은 '잠긴 오늘' 카드예요.

❓ **Q10 - 홈 하단과 기록 탭 제안대로 갈까?**

💬 "일단 니 알아서."

➡️ 결정:
- Round 4의 리드 제안대로 확정해요. 목업은 `home-final.html`이에요.
- 홈 하단 한 줄 목록은 상태에 따라 바뀌어요.
  - 순간을 안 올렸을 때: 운세 한 줄
  - 운세가 지금 할 일일 때: 오늘의 순간(둘 다 남김) 한 줄
  - 둘 다 끝났을 때: 운세 요약 한 줄
  - 위 세 경우 모두 그 아래에 '지난 순간'이 항상 있어요.
- 기록 탭은 두 화면이에요.
  - 한 장씩: 어두운 풀스크린. 오른쪽 위 작은 사진을 누르면 상대 사진으로 바뀌고, 하트 하나와 "어제 · 날짜 ↓" 안내만 있어요.
  - 모아보기: 달력 격자. 남긴 날은 사진, 빈 날은 흐린 숫자예요. 오늘을 아직 안 남겼으면 점선 테두리로 표시해요.

❓ **Q11 - 눌러 보는 기록 탭 프로토타입(`record-prototype.html`)을 써 보니?**

💬 "기록 탭은 너무 좋은데 조금 더 SNS 느낌이 났으면. 셔터는 조금 아래에 두고, 누르게 만드는 게 필요해. 저게 무슨 버튼이지 싶음. 누르면 카메라 혹은 갤러리로 가겠지."

➡️ 결정 (프로토타입 v2에 반영):
- SNS 요소
  - 위쪽에 날짜별 스토리 줄이 있어요. 오늘은 색 링, 잠긴 오늘은 자물쇠로 표시해요.
  - 게시물 아래에 두 사람 아바타, 날짜·N일째, 한 줄 글(선택), 하트·댓글·보내기 아이콘, "서윤이 좋아해요", "댓글 N개 보기"가 있어요.
  - 사진을 두 번 탭하면 하트가 눌려요.
  - 댓글 시트에서는 이모지 한 번으로 반응할 수 있어요. 글 입력은 선택이에요.
- 올리기 버튼
  - 잠긴 오늘 화면 아래쪽에 큰 알약 버튼 "📷 내 순간 올리기"를 둬요. 맥박처럼 퍼지는 테두리로 눈길을 끌어요.
  - 버튼 아래에 "카메라로 찍거나 앨범에서 골라요"라는 설명을 둬요.
  - 누르면 이렇게 진행해요:
    1. 카메라로 찍기 / 앨범에서 고르기 시트가 떠요.
    2. 카메라 화면 또는 앨범 화면으로 가요.
    3. 한 줄 남기기(선택)를 하고 올리기를 눌러요.
    4. 오늘 게시물이 열려요.
  - 오른쪽 위 + 버튼도 같은 흐름이에요. 하루 한 장 규칙은 유지해요.
- 숫자 경쟁은 넣지 않아요. 좋아요 수 대신 "서윤이 좋아해요"로만 보여요. 자동 재생, 재촉 알림도 없어요.

❓ **Q12 - 기록 탭 v2로 확정?**

💬 "이대로 가자."

➡️ 결정: 기록 탭은 `record-prototype.html`(v2)로 확정해요.
