해 볼 것

  • 맨 아래 "내 순간 올리기" → 카메라 또는 앨범 → (한 줄은 선택) → 올리기. 올리면 오늘 게시물이 열려요.
  • 위쪽 동그라미(스토리 줄)를 누르면 그날로 가요. 위아래로 넘겨도 돼요(휠·트랙패드·↑↓).
  • 사진을 두 번 탭하면 하트가 커지며 눌려요. 아래 하트 아이콘으로도 돼요.
  • 댓글 아이콘 → 이모지 한 번으로 반응을 남길 수 있어요. 글은 안 써도 돼요.
  • 오른쪽 위 작은 사진을 누르거나 큰 사진을 좌우로 끌면 둘의 사진이 바뀌어요.
  • 모아보기(네모 네 개) → 달력. 사진 있는 날을 누르면 그날로 가요.

일부러 없는 것

  • 팔로워·좋아요 숫자 경쟁, 자동 재생, 재촉 알림
  • 사진 없는 날 페이지(스토리 줄에서도 건너뛰어요)
