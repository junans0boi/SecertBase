# 02. Spec — 게임 2.0 3차 (디자인 확정 반영 + 윷놀이 시스템 개편 + 텔레파시 19+)

> 2026-11-06 하루 작업의 결정 기록. 근거: 사용자 피드백("UI/UX가 2000년대 초반 느낌, 촌스럽다 — 고전적인 느낌을 현대 시대에서 만드는 느낌", "윷놀이 목업은 게임 같지 않다", 게임별 확정 의견).

## 1. 문제
- 윷놀이: 말판 위 말(얼굴 토큰)이 카드의 캐릭터와 달라 보이고, 상점 아이템(말 스킨 24종 + 윷 스킨 18종)이 많고 의미가 없다. 디자인이 2006년풍.
- 블랙잭·도둑잡기: 로비 제목·카운트다운이 만화체(Gaegu), 본문은 영문 전용 글꼴이라 한글이 기기 글꼴로 떨어져 2007년풍.
- 텔레파시: "살짝 매운맛"만 있고 성인용 수위 선택이 없다.

## 3. 윷놀이 시스템(상세는 `../game-renewal-2026-11-wave2/27-yut-system.md`)
- 캐릭터 홍길동·미호·놀부, 능력치 5개(던지기 힘·침착·방어·행운·기세), 세 캐릭터 합 15, 서버 규칙에 상한과 함께 적용
- 윷 스킨 9종(B~SSS), 말 스킨 폐지, 기존 윷 아이템은 같은 등급의 새 스킨으로 전환하는 마이그레이션 `0049_yut_system.sql`
- 공정성: 최강 장비 대 최약 구성 ≤ 55%, 캐릭터 맞대결 45~55% (시뮬레이션 테스트로 고정)
- 낮/밤 테마는 서버가 판·재대결마다 정해 두 사람이 같은 것을 본다(`theme: 'day'|'night'`)

## 4. 텔레파시 19+ 안전장치
- 질문: 살짝 매운맛 149개, 19+ 211개(`tone` m/s/both 태그), 19+ 판은 하드한 질문만
- 로비 경고 + **상대(비방장)의 명시적 동의** + 서버의 **성인 확인**(가입 생년월일, `adult_only`)
- 질문 은행 가드레일 테스트: 미성년·가족·비동의·모욕·3자 금지, 하드 질문 최소 개수
- 19+ 선택 시 "각오하고 시작하세요" 큰 경고(후속 PR #254)

## 5. 범위 밖
- 놀이 탭 게임 목록의 글꼴(Gaegu) 교체
- 윷놀이 동물 말 전용 일러스트(이모지로 대체했었고, 이번에 말 스킨 자체가 폐지됨)
- 연령 확인은 자기 입력 생년월일 기준(본인 인증 아님)
