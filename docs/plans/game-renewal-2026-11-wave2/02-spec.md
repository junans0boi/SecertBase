# 02. Spec — 윷놀이·텔레파시·그림 맞히기·고스톱 2.0

> 상태: `ready-for-agent` (사용자가 Spec → Map → 티켓 → 구현까지 진행을 맡김)
> 근거: `00-analysis.md`, `01-grilling.md`(Q1–Q32), 공용 기반 `../game-renewal-2026-11/04-foundation-api.md`

## Problem Statement

커플이 놀이에서 네 게임을 하면:
- **윷놀이**는 아이템을 많이 낀 쪽이 판돈 게임에서 70–78% 이깁니다. 빽도에 "도→모"가 발동하고, 잡기를 막으면 두 말이 한 칸에 겹치며, 재대결하면 판돈·캐릭터가 사라지고, 턴 시간 제한이 없습니다.
- **텔레파시**는 같은 방에서 매 판 똑같은 5문제가 같은 순서로 나오고, 지난 판 답이 새 판에 섞이며, 대기가 끝나지 않기도 합니다.
- **그림 맞히기**는 회색 선이 상대에게 안 보이고, 그림이 찌그러지고, 다시 들어오면 그림이 사라지고, 판이 끝나지 않을 수 있으며, 한 글자 단어는 힌트로 정답이 드러납니다.
- **고스톱**은 판쓸이·마지막 턴·고 배수·흔들기 배수 등 규칙이 틀려 돈이 잘못 오가고, 이기던 사람이 고민하다 잠수 기권패를 당하며, 화투 그림이 흐리고 손패가 화면에 안 들어갑니다.

## Solution

1차 파도와 같은 2.0으로 다시 만듭니다. 규칙 오류는 테스트로 고정해 고치고, 시간 제한·서버 시작·동의 재대결·시리즈를 붙이고, 게임마다 고급 테마를 입힙니다.

| 게임 | 핵심 변화 | 테마 |
|---|---|---|
| 윷놀이 | 아이템 영향 상한(최대 장착 승률 ≤55%), 빽도·방어·코인 보너스 버그 수정, 서버 시작·재대결 유지, 30초 턴·자동 행동, 서버가 보내는 이동 후보와 칩 트레이 UI, 말 수 2/3/4 | 한지 마당 |
| 텔레파시 | 2지선다 밸런스 10문제, 320문제 은행 + 방별 셔플 가방(32판 무반복), 서버가 문항·점수 관리, 15초 | 별빛 편지 |
| 그림 맞히기 | 획 프로토콜 v2(고정 4:3, 서버 획 기록·재생, 실행 취소, 지우개 분리), 서버 타이머, 자동 힌트·동의어·아까워요, 1,500 제시어 + 방별 무반복 | 아틀리에 스케치북 |
| 고스톱 | 규칙 전면 수정(판쓸이·마지막 턴·고·박·흔들기/폭탄·두 장 선택·도탄·재분배·총통), 25초 턴(고/스톱 자동 스톱), 정확한 정산 내역, 벡터 화투, 펠트 판 레이아웃 | 초록 펠트 |

## User Stories

### 공통
1. 커플로서, 로비에서 방장이 시작하면 바로 게임이 열리기를 원합니다(게임 화면에 시작 버튼이 없어야 함).
2. 플레이어로서, 상대가 자리를 비워도 판이 멈추지 않고 정해진 시간 뒤 안전하게 진행되기를 원합니다.
3. 플레이어로서, 다시 접속하면 하던 판이 그대로 이어지기를 원합니다.
4. 플레이어로서, 판이 끝나면 결과·이번 방 전적·한 판 더를 보고 싶습니다.

### 윷놀이
5. 판돈을 건 플레이어로서, 아이템 때문에 승부가 기울지 않기를 원합니다.
6. 플레이어로서, 윷가락이 실제로 던져져 구르다 멈추는 모습을 보고 싶습니다.
7. 플레이어로서, 던지기가 여러 번 쌓였을 때 칩을 골라 말을 옮기고 목적지가 하나만 또렷하게 보이기를 원합니다.
8. 플레이어로서, 짧게 하고 싶을 때 말 수를 줄여 시작하고 싶습니다.
9. 플레이어로서, 재대결해도 판돈·캐릭터가 그대로이고 선이 바뀌기를 원합니다.

### 텔레파시
10. 커플로서, 둘 중 하나를 고르는 밸런스 질문으로 서로 통하는지 확인하고 싶습니다.
11. 커플로서, 여러 판을 해도 같은 질문이 다시 나오지 않기를 원합니다.
12. 커플로서, 끝나면 몇 개가 통했는지와 문제별 서로의 선택을 보고 싶습니다.

### 그림 맞히기
13. 그리는 사람으로서, 그린 그대로(색·굵기·비율) 상대 화면에 보이기를 원합니다.
14. 맞히는 사람으로서, 다시 들어와도 지금까지의 그림이 보이기를 원합니다.
15. 그리는 사람으로서, 실행 취소·지우개·여러 색과 굵기를 쓰고 싶습니다.
16. 그리는 사람으로서, 상대의 추측을 실시간으로 보고 싶습니다.
17. 맞히는 사람으로서, 시간이 지나면 힌트가 조금씩 열리고, 비슷하게 맞히면 "아까워요"를 듣고 싶습니다.
18. 커플로서, 여러 판을 해도 같은 제시어가 반복되지 않기를 원합니다.

### 고스톱
19. 플레이어로서, 맞고 규칙대로 점수·배수·박이 정확히 계산되기를 원합니다.
20. 플레이어로서, 손패가 바닥 두 장과 맞으면 내가 고르고 싶습니다.
21. 이기던 플레이어로서, 고/스톱을 고민하다 시간이 지나도 지지 않기를 원합니다(자동 스톱).
22. 플레이어로서, 화투가 선명하고 손패 10장이 한 화면에 들어오기를 원합니다.
23. 플레이어로서, 딴 패가 종류별로 정리되고 점수·고·배수·예상 금액이 늘 보이기를 원합니다.
24. 플레이어로서, 정산 내역이 실제 옮겨진 코인과 정확히 맞기를 원합니다.

## Implementation Decisions

### 공통
- 서버: 각 게임을 `src/games/<game>.js` 모듈로(`register`, `startFromLobby`, `restart`, `restore`, `afk`, `dispose`), 엔진은 `src/<game>-engine.js` 순수 함수 + `random` 주입. 기존 `socket.js`의 해당 게임 핸들러·잠수 어댑터·복원·재시작 분기를 지움(다른 게임은 건드리지 않음).
- 로비 옵션 추가(`src/lobby-options.js`, `lib/screens/arcade/lobby_options.dart`): `yut.pieces` 4|3|2, `telepathy.rounds` 10|5|15, `telepathy.spicy` off|on, `catch.rounds` 6|4|8.
- 클라이언트: `games/<game>/` 폴더 + `GameController`, 기존 `*_screen.dart` 진입점 유지. 새 테마 `GameTheme.hanji`, `starlight`, `atelier`, `felt`.
- 기존 SocketService의 해당 게임 필드는 건드리지 않음(통합 때 정리).

### 윷놀이
- 엔진: 아이템 효과 합산 상한(판돈 게임과 무료 판 동일), 빽도 업그레이드 제외 + `sticks` 일치, 방어 한 번·상한 10%·막히면 한 칸 앞 정지, 코인 보너스 판당 판돈 30% 상한(정산 때만), `legalMoves(state, player)` → `[{moveIndex, pieceId, backdoDir?, to, path}]`, `autoMove`.
- 모듈: `startFromLobby`(캐릭터·배경음·판돈·말 수는 서버 로비 기록, 첫 순서 무작위), 30초 마감 + 자동 던지기/이동, 승자 가드, 정산 try/finally + `recordGameOutcome(gameId)`, `yut:<room>:last`로 재대결 유지·선 교대, 순서 타이머 `timerApi`.
- 아이템 표시: 기존 아이템 효과 토스트는 유지하되 실제 적용된 값으로.
- 화면: 한지 마당 테마, 나무 윷가락 던지기 애니메이션(서버 `sticks` 그대로 착지), 칩 트레이 + 단일 목적지 미리보기, 잡기·업기·골인 연출, `GameSfx` 레시피, 캐릭터 음성 유지, `GameResultOverlay`.

### 텔레파시
- 데이터: `src/data/telepathy-questions.json` 320개 `{id, cat, a, b, emojiA?, emojiB?, spicy}`, 불러올 때 검증(고유 id·한국어·14자).
- 엔진: `drawQuestions(bag, bank, n, {spicy, random})`(분야당 2개 상한, 최근 50개 뒤로), `judge`, `summary`.
- 모듈: 셔플 가방 `telepathy:<room>:bag`(1년), 상태 `{gameId, round, rounds, question, myPick, partnerPicked, deadline, serverNow, history, score, streak, bestStreak, series}`, 15초 마감(시간 초과 = 불일치), 기록은 시리즈만(승패 없음). 옛 `game:telepathy:select` 경로 삭제.
- 화면: 별빛 편지 테마, A/B 큰 카드 + VS 메달, 상대 "골랐어요" 표시, 동시 뒤집기, 통하면 빛줄기·색종이, 결과 등급·문제별 요약.

### 그림 맞히기
- 데이터: `src/data/catch-words.json` 약 1,500개 `{w, cat, diff, aliases[]}`(옛 `catch_words.js` 대체).
- 엔진: 단어 뽑기(방별 본 단어 제외, 난이도 라운드별), 정답 판정(정규화·동의어·한 글자 차이), 점수, 힌트 공개 일정.
- 모듈: 획 이벤트 `stroke {round, id, seq, tool:'pen'|'marker'|'eraser', color, w, pts:[[x,y]...]}`, `undo {round, id}`, `clear {round}`, 서버 획 기록(라운드별, 메모리 + Redis), `sync` 때 재생, 라운드 60초 타이머·자동 힌트, 추측 속도 제한, 본 단어 `catch:<room>:seen`(90일, 600개).
- 화면: 아틀리에 테마, 4:3 고정 보드(`AspectRatio`), 한 손가락 `Listener`, 완료 획 캐시(`Picture`) + 진행 중 획만 다시 그리기, 12색·굵기·연필/마커·지우개·실행 취소·전체 지우기(확인), 추측 말풍선(그리는 사람도), 글자 칸 힌트, 정답 연출, 결과 갤러리.

### 고스톱
- 엔진 규칙(01 Q25): 쓸은 턴 끝 판정, 마지막 턴 판정·나가리, 고 점수/배수 표준, 흔들기·폭탄 선언자만, 피박 7장 이하, 손패 두 장 선택(`hand_choice`), 도탄, 4장 재분배, 총통 10점 즉시 승리(거절 가능, 동시면 재분배). 실패 재현 테스트 먼저.
- 모듈: 25초 마감 + 단계별 자동 행동(고/스톱은 스톱), 3회 자동이면 기권·실제 점수로 지불, 정산 try/finally, `recordGameOutcome(gameId)`, 동의 재대결 + 이긴 사람이 선, 엔진 영문 사유를 코드로.
- 화투 그림: `lib/widgets/hwatu/` 벡터 화투 48장 + 뒷면, 크기 3종, 종류 배지·쌍피 표시.
- 화면: 초록 펠트, 상대·나의 딴 패 묶음과 개수, 열두 달 자리 바닥, 부채꼴 손패(들고 확정), 점수판(점수·고·×N 분해·예상 금액·힌트 칩), 날아가기·뒤집기·+피·쓸·뻑·폭탄 연출, 고/스톱 전체 패널, 정산 영수증.

## Testing Decisions
- 엔진 TDD. 분석의 재현 시나리오(가짜 판쓸이, 마지막 턴, 3고 배수, 빽도 업그레이드 등)를 실패 테스트로 먼저.
- 균형·무반복 테스트: 윷 아이템 최대 장착 승률 ≤55%(시뮬레이션), 텔레파시 연속 32판 중복 없음, 그림 맞히기 연속 50판 중복 없음.
- 소켓: 게임별 `test/<game>-socket.test.js`(서버 시작, 동작·거부, 마감 자동 행동, 재대결, 복원, 끝난 판 거부, 정산 한 번).
- 위젯: 360·430·데스크톱 넘침 없음, 시작 버튼 없음, 핵심 상태 표시.
- 통합 후 독립 코드 리뷰, 두 계정 실플레이.
