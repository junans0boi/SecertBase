# 27. 윷놀이 시스템 개편 — 캐릭터 능력치 + 윷 스킨

> 상태: 구현됨(서버·상점·클라이언트 연결). 화면 디자인 개편은 이 문서 범위 밖(다음 작업).
> 근거: "상점 윷 아이템이 양산형처럼 많고 의미가 없다" → 말은 캐릭터 3명으로 고정하고, 사는 것은 윷 스킨만 남긴다.

## 1. 원칙

- **공정이 먼저**다. 캐릭터 능력치와 윷 스킨 효과는 **같은 상한**(`yut-engine.js`) 아래에서 합쳐지고, 가장 강한 구성이 가장 약한 구성을 55% 넘게 이기지 못하게 시뮬레이션 테스트(`test/yut-balance.test.js`)로 고정한다.
- 말 스킨(`yut_piece`)은 없앤다. 말은 홍길동·미호·놀부 그림이다.
- 윷 스킨은 9종 + 무료 기본 윷. 등급이 오를수록 **겉모습(화려함)** 과 **효과(세기)** 가 같이 커진다.

## 2. 캐릭터와 능력치 5가지

능력치는 1~5(레벨 1은 효과 0, 레벨 5가 최대). 세 캐릭터의 합은 모두 15(트레이드오프).

| 능력치 | 뜻 | 효과(레벨당) | 레벨5 |
|---|---|---|---|
| 던지기 힘 `power` | 걸→윷·도→모 확률 | +0.3%p | +1.2%p |
| 침착 `calm` | 빽도가 나오면 다시 던진다 | +4%p | 16%(상한 12%) |
| 방어 `guard` | 잡힘 방어(한 번만 굴림) | +1.5%p | 6%p |
| 행운 `luck` | 윷·모 코인 보너스(판돈 %) + 빽도 뒤 추가 던지기 | +1% / +2%p | 4% / 8%p |
| 기세 `momentum` | 골인한 말이 더 적을 때 윷·모 확률 | +0.4%p | +1.6%p |

| 캐릭터 | 성격 | 힘 | 침착 | 방어 | 행운 | 기세 |
|---|---|---|---|---|---|---|
| 홍길동 | 균형·수비 | 3 | 4 | 4 | 2 | 2 |
| 미호 | 기술·행운 | 3 | 2 | 2 | 5 | 3 |
| 놀부 | 힘·욕심 | 5 | 1 | 3 | 3 | 3 |

- 행운은 무료 판에서도 의미가 있다(빽도 뒤 추가 던지기). 코인 보너스는 판돈이 있을 때만 쌓이고 판당 판돈의 30%까지, 정산 때 승자에게만 지급.
- 서버는 `game:yut:state`에 두 사람의 `characterStats`(1~5)와 상한 적용 후 실제 `effects`를 보낸다. 화면의 능력치 막대와 "효과" 칩은 같은 값에서 나온다. 로비 선택 카드는 클라이언트 표(`kYutCharacterStats`)를 쓰고, 테스트가 서버 표와 같은지 확인한다.

## 3. 효과 상한(캐릭터 + 스킨 합산)

| 효과 | 상한 |
|---|---|
| 던지기를 올리는 것(윷·모 확률 + 모 확률 + 역전/기세) 합 | 2.5%p(넘으면 같은 비율로 줄임) |
| 잡힘 방어 | 9%(이전 10% 이하 규칙 유지) |
| 침착(빽도 재던지기) | 12% |
| 빽도 뒤 추가 던지기 | 8% |
| 코인 보너스(윷·모/잡기) | 판당 판돈의 30%, 정산 때만 |
| 빽도 | 어떤 효과로도 윷·모로 올리지 않는다 |

## 4. 윷 스킨 9종 (`yut_yut`)

B·A는 코인 구매, S·SS·SSS는 뽑기 전용(기존 상점 규칙). 뽑기는 `game='yut'`·등급으로 고르므로 등급마다 1종 이상 있다.

| id | 이름 | 등급 | 가격 | 효과 | 값 |
|---|---|---|---|---|---|
| 110 | 대나무 윷 | B | 1,500 | 윷·모 확률 `yut_control_pct` | +0.4 |
| 111 | 단풍 윷 | B | 1,500 | 잡힘 방어 `piece_catch_resist_pct` | +2 |
| 112 | 달빛 윷 | A | 2,500 | 빽도 방어 `yut_backdo_shield_pct` | 8% |
| 113 | 옥 윷 | A | 2,500 | 윷·모 코인 `yut_win_coin_pct` | 판돈 4% |
| 114 | 얼음 윷 | S | 뽑기 | 잡힘 방어 | +4 |
| 115 | 번개 윷 | S | 뽑기 | 윷·모 확률 | +0.7 |
| 116 | 불꽃 윷 | SS | 뽑기 | 역전(지고 있을 때) `yut_overturn_pct` | +1 |
| 117 | 용의 윷 | SS | 뽑기 | 윷·모 코인 | 판돈 8% |
| 118 | 신들의 윷 | SSS | 뽑기 | 윷·모 확률 | +1.0 |

겉모습: B는 소재 그대로(줄무늬만), A는 은은한 빛(달빛 글로우·옥 광택), S는 기운이 뚜렷한 빛(얼음 투명·번개 노랑), SS는 반짝이는 별(불꽃·용), SSS는 무지갯빛 반짝임. 모르는 이름은 등급으로, 그래도 모르면 기본 윷으로 그려 절대 실패하지 않는다.

## 5. 마이그레이션 `0049_yut_system.sql`

- 새 스킨 9종을 id 110–118로 넣고(`ON DUPLICATE KEY UPDATE`) 효과 행을 다시 쓴다.
- 예전 윷(id 20–24, 40–57, 23종)은 **같은 등급** 새 스킨으로 대응표를 통해 바꾼다: 소유자에게 새 스킨을 `INSERT IGNORE`로 주고, 장착 중이던 `yut_yut`는 새 스킨으로 바꾼다. 소유 기록은 지우지 않는다.
- 말 스킨(`yut_piece`) **장착은 모두 해제**하고, 소유 기록은 남긴다(환불 없음 — 아래 "미정").
- 예전 윷·말 아이템은 `active=0, game='yut_legacy'`로 은퇴해 상점·도감·뽑기(`game='yut'`)에서 빠진다. `/api/shop/owned`도 은퇴 항목을 숨긴다.
- 여러 번 실행해도 같다. 테스트 `test/yut-system-migration.test.js`가 id 충돌 없음, 등급별 대응, 멱등·무삭제, 소유·장착 변환 시뮬레이션을 검사한다.

## 6. 클라이언트(기능만, 현재 디자인)

- 로비 캐릭터 카드에 능력치 5칸 막대와 성격 한 줄. 상대가 고른 캐릭터는 누를 수 없다.
- 판 카드: 캐릭터 + 윷 스킨 이름 + 실제 효과 칩, 카드를 누르면 장비 창(능력치 5칸 + 스킨 + 효과 전체).
- 상점·보관함: 윷 슬롯만(말 슬롯·기본 말 삭제), 소수 효과 수치(`+0.4`)와 한국어 효과 이름, 은퇴 항목 숨김.
- `YutStickLook`: 새 스킨마다 서로 다른 모습(테스트가 구분됨을 확인) + 등급 예비 모습.

### 6-2. 화면(2단계): 낮·밤 두 가지, 판마다 무작위

- 서버가 판을 시작할 때(그리고 재대결마다) `theme: 'day'|'night'`를 굴려 상태에 싣는다(두 사람 같은 값, 복원 시 유지, 테스트에서 주입 가능).
- 클라이언트는 `GameTheme.yutDay`/`yutNight`(옛 meadow 대체)와 `YutPalette`(낮 daylight / 밤 moonlight)로 매핑한다. 시안(HTML) 그대로: 2.5D 떠 있는 판 + 그림자, 카드 가장자리를 넘는 캐릭터 상반신, 두툼한 버튼(아래 5px 진한 가장자리), 던지기 도장 연출, 결과 화면.
- 로비는 두 사람 알약 + 큰 캐릭터 + 능력치 레이더 + 말 개수·판돈 분할 선택(`YutLobbyView`, 로비는 낮 팔레트). 상점의 윷 스킨은 장착 중 스킨 미리보기 + 등급 순 3열 카드(`YutSkinShop`).

## 7. 균형 수치(시드 고정, 판당 6,000판·스킨 조합 2,500판)

- 같은 구성끼리 49~51%, 캐릭터끼리(기본 윷) 모든 조합 45~55%(측정 47.6~52.4%).
- 가장 강한 실제 구성(캐릭터 + 스킨 아무거나) vs 맨 구성: 최대 53.7%(≤55% 고정).
- 모든 효과를 상한까지 올린 이론상 구성 vs 맨 구성(캐릭터는 서로 다름): 최대 53.8%(≤55% 고정).

## 8. 미정

- 옛 말 스킨을 가진 사람에게 코인 환불을 줄지(현재: 소유 기록만 보존, 보상 없음).
- 9종 윷 스킨의 구매 가격 재조정(B 1,500 / A 2,500은 기존 값 유지).
