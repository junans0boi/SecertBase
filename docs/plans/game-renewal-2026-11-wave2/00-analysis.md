# 00. 분석 — 윷놀이·텔레파시·그림 맞히기·고스톱 2.0 (2차 파도)

> 2026-11-05 · 방법: 게임마다 클라이언트·서버·엔진 코드를 끝까지 읽고, 규칙은 실제 엔진을 불러 스크립트로 재현했습니다(윷놀이 4천 판 시뮬레이션, 고스톱 규칙 탐침).
> 1차 파도(블랙잭·도둑잡기·원카드·패널티킥·해적 룰렛·제로)에서 만든 공용 기반(`../game-renewal-2026-11/04-foundation-api.md`)을 그대로 씁니다.
> 사용자 요구: "게임 로직은 문제가 절대 있으면 안 됨", 고스톱·그림 맞히기는 첨부한 화면의 느낌을 참고(이름·그림은 베끼지 않음), 텔레파시는 2지선다 밸런스 게임 + 문제 반복 해결.

## 0. 한눈에

| 게임 | 진단 핵심 | 심각도 |
|---|---|---|
| 윷놀이 | 규칙 뼈대는 맞음. **아이템이 승패를 좌우**(최대 장착 시 승률 70%, 전부 78.5%). 빽도에 "도→모" 아이템이 발동, 잡기 방어 시 두 말이 한 칸에 겹침, 재대결 시 판돈·캐릭터 사라짐, 정산 오류 시 끝난 판이 계속됨, 턴 시간 제한 없음 | 높음 |
| 텔레파시 | 문제 30개가 앱에 고정, 매 판 같은 시드로 섞어 **한 방에서는 매번 같은 5문제**. 지난 판 답이 새 판에 섞임, 실패 응답 무시로 대기 무한, 점수는 각 기기 따로 계산 | 높음 |
| 그림 맞히기 | 회색 선이 상대에게 흰색, 지우개 크기 다름, 화면 비율·키보드로 그림이 찌그러짐, **재접속하면 그림이 사라짐**, 지난 라운드 그림이 다시 나타남, 서버 타이머 없음, 한 글자 단어는 힌트로 정답 노출, 제시어 반복(5판 내 36%) | 높음 |
| 고스톱 | **규칙 오류 다수**: 가짜 판쓸이, 마지막 턴 판정, 고 배수(첫 고부터 ×2), 흔들기·폭탄 배수를 상대도 받음, 두 장 매치 선택 불가, 폭탄 후 도탄 없음, 턴 타이머 없음(이기던 사람이 잠수로 짐). 카드 그림이 60×91 저해상도라 흐림, 손패가 화면에 안 들어감 | 매우 높음 |
