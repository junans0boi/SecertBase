# 01. Grilling — 2차 파도 설계 결정

> 셀프 그릴링. 사용자가 "to-spec → wayfinder-map → to-tickets → 구현"까지 진행을 맡겼으므로 추천안을 바로 결정으로 확정합니다.
> 근거: `00-analysis.md`, 1차 파도 결정(`../game-renewal-2026-11/01-grilling.md`), 공용 기반(`../game-renewal-2026-11/04-foundation-api.md`).

## 공통

**Q1 범위?** → 윷놀이·텔레파시·그림 맞히기·고스톱 4종을 1차와 같은 2.0 수준으로. 1차 공용 기반(서버 게임 모듈, 서버가 로비 시작 때 판 생성, `GameController`, play_kit 테마·부품, `GameSfx`, 로비 옵션, 동의 재대결, 시리즈, 잠수 필터)을 그대로 씁니다.

**Q2 "게임 로직은 절대 문제 없어야"를 어떻게 보장?** → 엔진은 순수 함수 + `random` 주입 + TDD. 분석에서 재현한 오류마다 실패하는 테스트를 먼저 쓰고 고칩니다. 소켓 흐름은 `test/<game>-socket.test.js`(공용 하네스). 판돈 게임(윷·고스톱)은 정산 멱등(`gameId`)과 "끝난 판 동작 거부"를 테스트로 고정합니다. 통합 후 독립 코드 리뷰를 한 번 더 합니다.

**Q3 시간 제한?** → 네 게임 모두 서버 마감시각(`turnDeadline` + `serverNow`)과 자동 행동. 연속 3회 자동 행동이면 기권(공용 규칙). 자동 행동은 "가장 안전한" 행동입니다.

**Q4 판 시작?** → 로비 "게임 시작" = 서버가 판 생성(`startFromLobby`). 게임 화면에 시작 버튼 없음. 그림 맞히기의 "둘 다 시작 가능" 문제도 이것으로 해결.

**Q5 참고 화면?** → 고스톱·그림 맞히기 첨부 화면의 배치·느낌만 참고하고, 이름·로고·캐릭터·그림은 쓰지 않습니다.

## 윷놀이

**Q6 아이템 밸런스(Y1)?** → 아이템은 유지하되 **판돈 게임에서 승부 영향의 합계를 제한**합니다. 던지기 계열(`yut_control_pct`·`yut_mo_rate_pct`·`yut_overturn_pct`·`yut_backdo_bonus_pct`)은 효과를 합산해 상한을 두고, 방어 계열은 한 번만 굴리며 상한 10%. 목표: 한쪽만 최대 장착해도 **승률 55% 이하**(시뮬레이션 테스트로 고정). 코인 보너스류는 정산 때만, 판당 상한(판돈의 30%) 안에서. 무료 판(판돈 0)은 아이템 효과를 그대로 둬도 되지만 같은 상한으로 단순화합니다.

**Q7 방어 성공(Y3)?** → 잡기가 막히면 **움직이던 말이 바로 앞 칸에 멈춥니다**(같은 칸 겹침 없음). 앞 칸에도 상대 말이 있으면 방어는 실패로 보고 정상적으로 잡습니다.

**Q8 빽도 업그레이드(Y2)?** → 빽도에는 "도→모"가 발동하지 않습니다. 결과가 바뀌면 `sticks`도 결과와 같게 다시 만듭니다(막대 그림이 결과와 항상 일치).

**Q9 판 흐름?** → 서버 시작, 캐릭터·배경음·판돈은 서버 로비 기록에서, 첫 순서는 무작위(주사위 대신 "윷 던져 순서 정하기" 연출만 유지해도 결과는 서버 무작위), 재대결은 `yut:<room>:last`로 판돈·캐릭터·배경음·시리즈 유지 + 선 교대, 승자 가드와 정산 try/finally, 순서 타이머는 `timerApi` + gameId 확인.

**Q10 턴 시간?** → 30초. 던지기 단계는 자동 던지기, 이동 단계는 서버가 고른 "최선 이동"(잡기 > 골인 > 가장 앞선 말). 쌓인 던지기도 하나씩 같은 방식.

**Q11 이동 UI(Y11)?** → 서버가 `legalMoves`(던지기 번호·말·빽도 방향·경로)를 보내고, 화면은 규칙을 다시 계산하지 않습니다. 아래에 **던지기 결과 칩 트레이** → 칩 선택 → 말 선택 → 목적지 하나만 미리보기(붓 경로 애니메이션) → 확정. 빽도 갈림길은 화살표 두 개.

**Q12 말 수?** → 로비 옵션 `pieces` 2/3/4(기본 4). 2개면 약 5분 짧은 판.

**Q13 테마?** → **한지 마당**: 한지 질감 배경, 먹선 판, 오방색(청·적·황·백·흑) 포인트, 멍석 위 나무 윷가락이 포물선으로 날아가 구르다 서버 결과대로 멈추는 연출(윷·모는 슬로모션 + "윷이야!"), 잡기 먹물 번짐, 골인 오방색 색종이. 소리는 `GameSfx` 레시피(윷가락 딱딱, 북·꽹과리, 징). 기존 캐릭터 음성은 유지.

## 텔레파시

**Q14 규칙?** → **밸런스 텔레파시**: A vs B 두 개 중 하나를 둘이 몰래 고르고 동시에 공개. 같으면 "통했다!". 한 판 10문제(로비 옵션 5/10/15), 문제당 15초, 시간 초과는 "시간 초과"로 불일치 처리. 점수 = 통한 개수, 연속 통하면 🔥연속 표시, 최고 연속 기록.

**Q15 승패?** → 협동 게임이라 승패 기록은 하지 않고(무승부 기록·코인 없음), **방 시리즈에 판별 통한 비율·최고 연속**을 남깁니다. 결과 화면: N/10과 등급 문구(9–10 "텔레파시 커플", 7–8 "눈빛만 봐도", 4–6 "알아가는 중", 0–3 "반대가 끌려요"), 문제별 두 사람의 선택 요약, 한 판 더.

**Q16 문제 은행·반복(T1–T2)?** → 서버 JSON(`src/data/telepathy-questions.json`) **320문제**(8분야 × 40: 가벼운 취향, 음식·야식, 데이트, 여행, 일상·습관, 연애·로맨스, 만약에, 살짝 매운맛). 고정 id, 한국어만, 보기 14자 이내. 방(커플)별 **셔플 가방**을 Redis에 1년 보관: 판 시작 때 가방에서 10개를 꺼내고, 다 쓰면 전체를 다시 섞되 최근 50개는 뒤로. 판당 분야별 최대 2문제. **10문제 기준 32판 동안 한 번도 반복 없음**(테스트로 고정). 매운맛은 로비 옵션 `spicy` 끄기/켜기(기본 끄기).

**Q17 흐름?** → 서버가 문항·라운드·점수를 모두 가짐(`game:telepathy:state`), 클라이언트는 `pick {round, choice:'A'|'B'}`만. 세션은 판 id로 구분해 지난 판 답이 섞이지 않음. 재접속은 `sync`로 복원.

**Q18 테마?** → **별빛 편지**(새 `GameTheme.starlight`): 밤하늘 남보라 + 별가루, 두 카드가 위아래로 놓이고 가운데 "VS" 메달, 공개 때 두 카드가 함께 뒤집히고 통하면 두 사람 아바타 사이로 빛줄기가 이어짐.

## 그림 맞히기

**Q19 흐름?** → 서버 시작, 서버 라운드 타이머(60초), 라운드 수 로비 옵션 4/6/8(기본 6), 그리는 사람 번갈아, 잠수 처리, 재대결·시리즈, `gameId` 기록.

**Q20 그림 동기화(C1–C7)?** → **획 프로토콜 v2**: 고정 4:3 보드 좌표(0–1, 비율 고정), 굵기도 보드 너비 기준 상대값, 33ms 묶음 전송 + 손 뗄 때 즉시 전송, 획 id·순번, 실행 취소(`undo {strokeId}`)·전체 지우기, **서버가 라운드의 획 기록을 보관**해 `sync`·재접속 때 다시 그려 줌. 지우개는 별도 도구(색 번호와 분리), 받는 쪽과 같은 굵기. 점(탭)도 그려짐. 한 손가락만.

**Q21 그리기 도구?** → 12색(검정·회색·갈색·빨강·주황·노랑·초록·하늘·파랑·보라·분홍·살구), 44px 이상, 굵기 3단계 미리보기, 연필·마커 두 가지 질감, 지우개, 실행 취소(최대 20), 전체 지우기(확인). 보드는 키보드가 올라와도 줄지 않음(입력창이 보드 위에 겹쳐 뜸).

**Q22 힌트·정답(C9–C10)?** → 분야는 처음부터 공개. 글자 수 칸 표시, **30초·15초에 한 글자씩 자동 공개**(3글자 이상만). 직접 힌트는 1점 차감. 추측은 0.7초에 한 번. 정답 판정은 공백 제거 + NFC + 소문자 + **동의어**(`aliases`), 한 글자 차이면 "아까워요!". 점수: 맞힌 사람 3 + 남은 시간 보너스(20초당 1), 그린 사람 2.

**Q23 제시어(C11)?** → 정리 후 약 **1,500개**(분야당 약 70, 중복·상표·무기·그리기 어려운 말·영문 혼용 제거), `{w, cat, diff 1–3, aliases}`. 라운드 1–2 쉬움, 3–4 보통, 5–6 어려움. 방별 **본 단어 기록**(Redis 90일, 최대 600개) → 약 100판 동안 반복 없음.

**Q24 화면?** → **아틀리에 스케치북**(새 `GameTheme.atelier`): 크림색 종이 질감 보드에 스프링 철, 파란 테두리(참고 화면의 느낌), 양옆에 두 사람 배지와 점수, 보드 위에 글자 칸 힌트와 카운트다운, 추측은 말풍선으로 배지에서 튀어나오고 **그리는 사람도 봄**, 정답이면 글자 칸이 뒤집히며 색종이·"정답!", 결과 화면에 라운드별 그림 갤러리.

## 고스톱

**Q25 규칙 기준?** → 2인 맞고 일반 규칙으로 고정하고 도움말에 명시합니다.
- 7점 이상 나면 고/스톱. 고: 1고 +1점, 2고 +2점, 3고부터 +3점에 ×2, 이후 고마다 ×2 추가.
- 박: **피박**(이긴 쪽이 피로 점수를 냈고 진 쪽 피 7장 이하), **광박**(이긴 쪽이 광 점수를 냈고 진 쪽 광 0장), **고박**(고를 외친 사람이 지면 고박으로 두 배 지불).
- 흔들기·폭탄: 선언한 사람이 이길 때만 ×2(각각).
- 쓸(판쓸이): **턴이 끝났을 때** 바닥이 비면 피 1장, 마지막 턴 제외.
- 마지막 턴: 마지막에 점수를 낸 사람만 승리. 고를 외치고 점수가 안 오른 채 패가 떨어지면 **나가리**(다음 판 배수 ×2는 이번 범위 밖, 안내만).
- 손패가 바닥 두 장과 맞으면 **직접 선택**. 폭탄 후 **도탄 2번**(뒤집기만). 분배 시 바닥 같은 월 4장 → 재분배. 총통: 즉시 승리 10점(거절 가능, 둘 다면 재분배).
- 국진(9월 열끗)은 열끗 고정, 보너스 피 없음(도움말에 명시).

**Q26 시간 제한(G11)?** → 내 턴 25초. 자동 행동: 패 내기 = 코치가 고른 패, 선택 = 점수 높은 쪽, 흔들기 = 안 함, **고/스톱 = 스톱**(이기던 사람이 잠수로 지는 일 없음). 3회 연속 자동이면 기권, 기권패 지불은 **실제 점수와 배수**로(7점 고정 아님).

**Q27 정산?** → `recordGameOutcome(gameId)` 한 번, 정산 try/finally, 정산 내역(점수·고·박·흔들기·폭탄·배수·실제 이동 코인)이 화면 합계와 정확히 같게. 재대결은 동의 절차 + 이긴 사람이 선.

**Q28 카드 그림(G13)?** → 저해상도 PNG를 버리고 **새 벡터 화투**(CustomPainter)를 직접 그립니다. 열두 달 꽃·새·달 모티프를 현대적인 평면 일러스트로, 종류 배지(광·열·띠·피, 쌍피 "2")를 모서리에, 고급 뒷면(진홍 + 금박 무늬). 작은 크기에서도 월·종류가 구분되게.

**Q29 화면?** → **초록 펠트 판**(참고 화면의 느낌): 위에 상대 배지·딴 패(광·열·띠·피 묶음 + 개수, 쌍피 표시), 가운데 열두 달 자리로 정렬된 바닥 + 더미(뻑 더미 표시), 아래 손패 10장이 360px에 겹쳐 들어가는 부채꼴, **누르면 들리고 한 번 더 누르면 냄**. 점수판: 점수·고 횟수·큰 ×N 배지(고·흔들·폭탄·박 분해), 예상 금액, "홍단 1장 남음" 같은 힌트 칩. 연출: 손패가 바닥으로 날아감, 더미 패 3D 뒤집기, 먹은 패가 딴 패로 날아감, "+피 1" 떠오름, 피 뺏기 화살표, 쓸 금빛 고리, 뻑 도장, 폭탄 흔들림. **고/스톱 순간**은 화면 전체 패널(지금 받을 금액 vs 고 했을 때, 상대 위협). 소리: 패 착, 뒤집기, 먹기, 뻑, 쓸, "고!", 정산 동전.
