# 04 기지 위젯 (Android 홈 화면 위젯)

## What to build
`home_widget`으로 Android 위젯 2종: ① D-day(+다음 기념일), ② 오늘 상태(마주 열기 여부, 오늘의 루프 공개 여부, 읽지 않은 쪽지 수). 앱이 데이터를 갱신할 때와 푸시 수신 시 위젯 갱신. 위젯에는 사진·쪽지 본문 등 민감 내용을 넣지 않는다. 디자인은 직접 만든 기지 색 토큰 사용.
## Acceptance
- [ ] 위젯 데이터 직렬화 단위 테스트, 앱 쪽 갱신 호출 테스트, 에뮬레이터 수동 확인 기록.
