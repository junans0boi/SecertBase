# 기록 탭 리디자인 — 결정 사항 (2026-11-12)

베타 테스트 전에 기록 탭과 오늘의 순간을 "자유롭게 쌓는 우리의 기록"으로 바꾼다.
목업: `record-options.html`(첫 3안, 올리기, 잠금) → `record-concepts.html`(콘셉트 3안)
→ `record-multi.html`(여러 장 보기 3안).

## 왜
- 지금 기록 탭은 정해진 흐름에 갇힌 느낌이 든다. 스토리가 자동으로 넘어가고, 오늘의 순간 규칙과 잠금이 있다.
- 지난 날을 그날 날짜로 올리기 어렵다.
- 하루에 여러 장 올리면 피드에서 다 보이지 않는다.
- 다른 앱을 베낀 느낌이 아니라, "우리 둘"이라는 정체성이 보여야 한다.

## 정한 것
1. **핵심 행동: 자유롭게 기록을 쌓는다.**
   - 날짜는 내가 고른 날로 정한다. 기본값은 사진 찍은 날이다.
   - 3일 전에 논 기록도 그날 날짜로 쌓인다.
2. **기록 탭 이름과 구조: "우리의 하루".** 위쪽에서 `피드 | 달력`을 전환한다.
   - **피드 (α 두 줄 스트립)**
     - 하루 = 카드 1장. 헤더에 날짜와 장소·장수를 보여준다.
     - 그 아래 **"나" 한 줄, "서윤" 한 줄**을 두고, 각 줄은 옆으로 밀어 그날 올린 사진·영상을 전부 본다. 컷마다 시각을 표시한다.
     - 빈 줄: 상대가 안 올렸으면 "서윤의 하루를 기다려요"를 보여준다. 내가 안 올렸으면 "내 하루 채우기"를 보여주고, 누르면 **그 날짜로** 올리기가 열린다.
     - 카드 아래에 한 줄(캡션)과 하트·댓글을 둔다.
   - **뷰어**
     - 사진을 누르면 그날 사진 전부를 **시간순으로** 크게 넘겨본다.
     - 아래 썸네일(나·서윤 색 점)로 원하는 장으로 바로 이동한다.
     - 자동으로 넘어가지 않는다.
   - **달력**
     - 날짜 칸을 반으로 나눠 나·서윤 사진을 보여준다. 둘 다 남긴 날이 한눈에 보인다.
     - 칸을 누르면 그날 카드로 간다.
   - 지금의 스토리 자동 재생(5초 넘김, 꾹 눌러 멈춤)은 없앤다.
3. **올리기: 고르기 → 편집 → 바로 올리기.**
   - 편집 화면 아래에 한 줄 입력, **날짜 칩**, 장소 칩을 두고 `올리기`로 끝낸다.
   - 지금의 캡션·장소·날짜 화면은 없앤다.
   - 날짜 칩의 기본값은 사진 찍은 날(EXIF, 없으면 파일 날짜)이다.
   - 날짜 칩을 누르면 시트가 열린다: 오늘 / 어제 / 그저께 / 사진 찍은 날 / 달력. 미래 날짜는 고를 수 없다.
   - 장소는 선택이다. 올린 뒤에도 고칠 수 있다.
4. **오늘의 순간: 잠금은 홈의 오늘의 순간에만 둔다.**
   - 잠긴 칸에 이유를 쓴다: "내 순간을 올리면 서윤의 순간이 열려요".
   - 기록 탭에 올리는 일반 기록에는 잠금이 없다.
5. **하단바:** 이미 배포된 떠 있는 캡슐을 그대로 쓴다.

## 아직 정하지 않은 것 / 확인할 것
- 서버의 오늘의 순간 잠금이 기록 탭 피드에 어떤 영향을 주는지 확인한다.
  - 상대의 오늘의 순간 게시물이 피드에서 가려지는지 확인한다.
  - 가려진다면 그 칸에 무엇을 보여줄지 정한다(잠금 안내 칸으로 보여줄지 등).
- 날짜 각인 같은 시각 포인트는 1차 구현 뒤에 덧붙일지 결정한다.
- 영상이 많은 날의 스트립 성능을 확인한다(썸네일 우선).
