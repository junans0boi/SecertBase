## Destination

`main`에서 갈라진 브랜치들에 다음이 반영되어 푸시된 상태입니다. 머지는 사용자 확인 뒤입니다.

- 블랙잭·도둑잡기·제로·해적 룰렛·패널티킥·원카드가 **2.0**입니다(규칙 보정 + 게임별 고급 테마의 새 화면 + 합성 효과음).
- 공통 장치(벡터 카드, 공용 효과음 엔진, 게임 테마 토큰, 로비 옵션, 재대결 합의, `gameId` 멱등 저장, 시리즈 전적, 게임별 잠수 안내, 공용 리액션)가 6종에 적용되어 있고, 다음 파도의 8종이 그대로 쓸 수 있습니다.
- 서버 테스트와 `flutter analyze`·`flutter test`가 통과하고, 균형 테스트가 목표 범위 안입니다.
- 두 테스트 계정으로 6종을 각각 끝까지 실플레이해 확인했습니다.
