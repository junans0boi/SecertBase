# 20: 원카드 2.0 화면 (자정의 카드 살롱)

**Type:** client

**Blocked by:** 02, 03, 05, 18, 19

**Status:** ready-for-agent

## What to build

원카드를 **자정의 카드 살롱** 테마로 새로 만든다. 무슨 색을 내야 하는지, 누구 차례인지, 상대가 몇 장 남았는지가 한눈에 보이고, 휴대폰 폭에서도 손패를 편하게 고를 수 있어야 한다(00-analysis §6b U1·U3·U7·U8·U9, 01-grilling Q49–Q55).

## Acceptance criteria

- [ ] 테마 **자정의 카드 살롱**: 깊은 플럼 벨벳 테이블 + 금박 테두리, 카드 4색(로즈·허니·스카이·세이지)을 보석 톤으로. 색·배경은 `GameTheme`/`GameBackdrop`(티켓 03)만 사용, 탱크 2.0 이상의 완성도
- [ ] `games/onecard/` 폴더 + 얇은 진입점. `uno_board.dart`의 1.0 코드는 정리(카드 뒷면 아이템 스킨 표는 유지)
- [ ] 게임 화면 안의 \"새 게임 시작\" 제거. 생성 실패 시 방장만 \"다시 시작\", 상대는 \"방장이 준비 중\", 실패 사유 표시
- [ ] 위: 상대 칩(프로필 이모지·닉네임·남은 장수·차례 빛·\"1장 남음\"), 겹친 뒷면 부채. 사용자 코드 노출 없음
- [ ] 가운데: 뽑을 더미, 버린 더미(와일드는 고른 색으로 물듦), 항상 보이는 \"지금 색\" 칩, 쌓인 벌칙 배지 +N
- [ ] 아래: 폭 360~430에 맞춰 겹치는 부채꼴 손패, 낼 수 있는 카드만 들림, 새로 뽑은 카드 NEW 빛
- [ ] \"원카드!\"(외치기)와 \"잡기!\" 분리, 서버 `turnDeadline` 시간 링, 공용 리액션 바(도전 버튼을 가리지 않음)
- [ ] 영어 글자 제거: 카드 면은 ⊘ ⇄ +2 +4 ◐ \"모두\". `voice_uno.mp3`를 들어 \"UNO\" 발음이면 합성음으로 대체
- [ ] 연출: 덱→손 딜, 손→더미 내기, 뽑기, 모두 버리기 쓸기, 색 변경 빛 번짐, 승리 금빛 \"원카드!\" 배너
- [ ] 소리(`recipes/onecard.dart`): 상대 내기·뽑기·잡힘·도전 결과·내 차례·시작까지
- [ ] 결과 `GameResultSheet`: 남은 손패, 코인 변화, 몰수 여부, 전적, 재대결은 동의 절차만
- [ ] 거부 사유 7개(`cannot_play_card` 등) 한국어 안내
- [ ] 위젯 테스트: 지금 색 표시(와일드 포함), 비방장에게 시작 버튼 없음, 360 폭 7장·15장 손패 오버플로 없음, 외치기/잡기 버튼 상태, 결과 시트 몰수 문구
- [ ] 두 계정 실플레이: 고와일드·클래식 각 한 판(쌓기, 도전, 원카드 외치기·잡기, 시간 초과, 재대결 선공 교대)을 PR에 기록
