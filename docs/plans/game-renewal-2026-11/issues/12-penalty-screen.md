# 12: 패널티킥 2.0 화면

**Type:** client

**Blocked by:** 02, 03, 11, 18

**Status:** ready-for-agent

## What to build

귀여운 마스코트와 **선셋 스타디움**(고급스럽지만 밝은 노을 톤), 한 번에 이해되는 조작으로 패널티킥을 새로 만든다. 방장이 로비에서 3칸/6칸을 고른다. 처음 하는 사람도 쉽게 즐길 수 있어야 한다.

## Acceptance criteria

- [ ] 테마 **선셋 스타디움**: 노을 하늘 + 관중석 보케 + 빛나는 잔디, 민트(나)·코럴(상대)·골드 포인트. 골 순간 슬로모션 + 그물 출렁 + 색종이. 색·배경은 `GameTheme`/`GameBackdrop`(티켓 03)만 사용, 탱크 2.0 이상의 완성도(질감·조명·모션)
- [ ] `games/penalty/` 폴더 + 얇은 진입점
- [ ] 로비: 방장에게 "3칸 · 심리전 / 6칸 · 정밀" 선택 카드(설명 한 줄씩), 상대는 고른 값을 실시간으로 본다(티켓 18)
- [ ] 경기장: 노을 하늘 그라데이션, 관중석 보케, 빛나는 잔디 줄무늬, 큼직한 골대. 3칸은 터치 영역 3개 + 아래 큰 버튼 3개, 6칸은 영역 6개 + 버튼 3열×2행. 거칠거나 칙칙한 요소 없음
- [ ] 마스코트: 둥근 몸 + 유니폼(나=민트, 상대=분홍) + **얼굴은 프로필 이모지**(`profileEmojis`). 키커 걷기→킥, 키퍼 다이브 모션
- [ ] 상단: 점수판 ●○ 5개씩, **상대의 지난 킥 방향 기록 최근 5번**, 남은 시간 링(20초)
- [ ] 조작: 탭으로 방향 선택(하이라이트) + 큰 "슛!"/"막기!" 버튼 하나로 확정
- [ ] 연출: 공 비행 0.9초 + 키퍼 다이브 + 그물 출렁 + 관중 환호/탄식 + 색종이 또는 "나이스!". 탭으로 건너뛰기
- [ ] 첫 판 요약 오버레이(3줄 이내: "골대 칸 중 하나를 골라요. 키퍼가 같은 칸을 고르면 막혀요!") + 상단 `?` 버튼. `penalty_tutorial_seen` 저장
- [ ] 효과음: 휘슬, 킥, 그물, 환호, 탄식, 선방 (`recipes/soccer.dart`)
- [ ] 결과 `GameResultSheet`(무승부 포함, 전적, 재대결). 게임 안 별도 시작 제거, 로비 설명 문구 갱신
- [ ] `GameMenuListener`/`GameScaffold(gameType: 'penalty')`
- [ ] 위젯 테스트: 3칸·6칸 영역 탭 선택, 확정 버튼 상태, 상대 킥 기록 표시, 첫 판 오버레이 1회 표시, 폭 360
- [ ] 두 계정 실플레이 3칸·6칸 각 한 판(골·선방·서든데스·시간 초과 자동 선택)을 확인하고 PR에 기록
