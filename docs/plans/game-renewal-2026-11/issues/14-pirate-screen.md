# 14: 해적 룰렛 2.0 화면

**Type:** client

**Blocked by:** 02, 03, 13, 18

**Status:** ready-for-agent

## What to build

**해적선 야경** 테마(젖은 나무 갑판·랜턴 빛·황동)에서 통 위에 구멍이 있고 칼이 꽂히며, 긴장이 오르다가 해적이 날아가고, 이긴 사람이 정한 벌칙 카드가 열리는 해적 룰렛을 만든다.

## Acceptance criteria

- [ ] 테마 **해적선 야경**: 젖은 나무 갑판 + 랜턴 빛 + 양피지, 황동·랜턴 오렌지 포인트. 칼이 꽂힐 때 통 삐걱, 터지면 해적이 하늘로. 색·배경은 `GameTheme`/`GameBackdrop`(티켓 03)만 사용, 탱크 2.0 이상의 완성도(질감·조명·모션)
- [ ] `games/pirate/` 폴더 + 얇은 진입점. 방장 전용 UI(`_isHost`) 전부 제거
- [ ] 통 하나를 크게(원기둥 앞면), **구멍은 통 몸통 위** 가로 2~3줄, 번호는 작게. 별도 숫자 격자 제거
- [ ] 칼 꽂기: 위에서 떨어져 구멍에 꽂히는 0.35초 + 통 흔들림 + 칼 꽂는 소리. 꽂힌 구멍에는 칼이 보임
- [ ] 긴장: 폭탄 확률 게이지(%)와 해적 표정 4단계(여유→걱정→땀→비명). 30%↑에서 통 떨림
- [ ] 폭발: 뚜껑이 열리고 해적이 하늘로 날아감(별·파편, 만화풍), "펑!" 소리
- [ ] 벌칙 단계: 이긴 사람은 프리셋 칩 10개 + 직접 입력(30자 제한·빈 값 불가), 진 사람은 "◯◯이(가) 벌칙을 고르는 중…". 정해지면 큰 벌칙 카드 + "했어요!" 버튼, 이긴 사람에게 완료 알림
- [ ] 구멍 수는 로비에서 방장이 고름(빠른 6 / 보통 8 / 길게 12, 티켓 18). 게임 화면 안의 시작 화면·시작 버튼 제거
- [ ] 효과음: 칼 꽂기, 통 삐걱, 폭발, 해적 날아감, 벌칙 카드 (`recipes/pirate.dart`)
- [ ] 결과 `GameResultSheet`(전적, 재대결). 게임 안 이중 시작 제거, 로비 설명 문구 갱신
- [ ] 위젯 테스트: 구멍 수별(6~12) 배치·오버플로 없음, 확률 게이지 값, 벌칙 입력 검증
- [ ] 두 계정 실플레이 한 판(터짐·벌칙 정하기·"했어요"·재대결)을 확인하고 PR에 기록
